
# 人们与道法少女的合作

## 认知屏障时期
- 有认知屏障时，人们无法做出正确判断
- 只有少数拥有[[阴阳眼]]的人能正确认识到**灾兽和道法少女**

## 认知屏障解除后（2008年[[灵明]]突破道域巅峰后）
- 有阴阳眼的人、各国高层、军队能正确认识到灾兽和道法少女

## [合作内容](确定合作缘由)
1. 为道法少女提供合适的身份
2. 道法少女在哪觉醒的就在哪任命，不得随意分配
3. 低等级的道法少女（道仪境之前）与军队一起战斗
4. 道法少女女王为军队提供一只[[道灵]]（一直细分到小队）
5. **道法少女偶像**（以爻衡、爻变为大多数，极少数道仪境）：
   - 民众安抚
   - 公关需求
   - 兵源激励
   - 募集资金等
1. 部分法理境道法少女作为国家守护者

## 四代转爻
- 转爻器是[[天巧]]通过自己和[[天姝]]和[[天何]]的权能联合制作的，拥有更强的觉醒权能
- 天巧制作的转爻器交予官方，官方想办法去帮助觉醒道法少女


# 各级灾兽应对措施

## 核心规则
- 都需要**道法少女**补刀才能彻底击杀，否则会[复活](未彻底消灭的复活案例.md)（复活期间灾难依旧）

## 分级应对
| 灾兽等级     | 人类应对措施                            |
| -------- | --------------------------------- |
| E级（异兆）   | 全副武装的小队（单人足够勇猛）                   |
| D级（动荡）   | 装甲连 + 空中支援                        |
| C级（崩坏）   | 合成旅                               |
| B级（浩劫）   | 可用战略武器单刷（不实用不用，一般辅助道法少女解决战斗）      |
| A级（破灭）   | 人们只能做到辅助压制                        |
| S级（苍渊）   | 人们无能为力                            |
| SS级（终焉）  | 除非同级的道法少女，或拥有特殊能力的道域巅峰道法少女，否则无能为力 |
| SSS级（永恒） | 宇宙末日，几乎无法战胜                       |

## SSS永恒灾兽的应对
- SSS永恒灾兽诞生前，所有普通人与不到道域巅峰的道法少女全部迁到[[异界]]去
- 只要不是道域境巅峰都强制撤离，没有商量余地，只有事先通知和执行
- 即便是最强的道域巅峰道法少女[[天钧]]，也被SSS永恒灾兽诞生前的满溢重伤
