# 道法少女历史时期

## 概述
道法少女的历史分为两大时期，以人类能否觉醒道法少女为分界线。

---

# 第一时期

## 一、应劫而生

### 1. 自然诞生道法少女
因天道、星辰而生。

| 道法少女   | 诞生时间   | 诞生缘由           |
| ------ | ------ | -------------- |
| [[清止]] | 七万年前   | 灾兽第一次出现后，因天道而生 |
| [[天钧]] | 一万两千年前 | 因星辰而生          |

### 2. 文明诞生道法少女
因文明诞生，与特殊灾难一同出现，属于**文明自救**。

| 道法少女                       | 说明        |
| -------------------------- | --------- |
| [[术语表#四大文明道法少女\|四大文明道法少女]] | 与特殊灾难一同诞生 |


---

## 第一时期结束标志

**公元前1177年，青铜时代崩溃。**

第三位文明道法少女彻底死亡。

三位文明道法少女的彻底死亡所产生的**文明之力**，提前使道法少女体系在本世界稳定下来——**人类中可以觉醒道法少女**。

---

# 第二时期

## 一、初始

### 特征
- 道法少女刚诞生就死在灾兽手里

### 初始结束标志
- **[[天姝]]存活**（成功活下来一位人类转爻道法少女）

---

## 二、早期

### 关键事件

| 时间        | 事件                                                                 |
| --------- | ------------------------------------------------------------------ |
| 公元前331年   | [[天姝]]从没有危险的状态下觉醒——第一位成功活下来的人类转爻道法少女                               |
| 公元前314年   | [[天烛]]觉醒——唯一一个觉醒就是法理境的天才，第二位成功活下来的道法少女                             |
| 天姝突破道域巅峰后 | 开创三代“[[道灵]]觉醒”方式                                                   |
| 天烛突破道域巅峰后 | 穿越到异界，碰上一个被灾兽摧毁的世界，与灾兽战斗。最后大败而归，在本界沉睡百年。苏醒后与其他道法少女一起观察本界未来，得知本界会灭亡 |
| 之后        | 所有道域巅峰共同决定：把天烛遇到的那个异界打下来，用作[[第一方舟\|方舟]]                            |

### 打下异界的理由
- 为了报仇
- 为了生存
- 将这个被灾兽摧毁的世界回收

### 早期结束标志
- **公元200年**：连接两界，开始为后续的退路做准备

---

## 三、前期

### [[三灾时期|三灾灭绝事件]]

#### 829年
道域巅峰道法少女正在讨伐异界终焉灾兽时，本界诞生终焉灾兽。

五位道域巅峰道法少女分别与两头终焉灾兽战斗，成功消灭灾兽。

**代价**：
- [[天何]]（文明道法少女）与[[天钧]]（星辰道法少女）暂时死亡
- 其他三位沉睡

#### 831年
本界又诞生一个终焉灾兽。

以**牺牲所有非道域巅峰道法少女**的代价，将灾兽消灭。

### 前期结束标志
- **道法少女几乎灭绝**

---

## 四、中期

### 关键事件

| 时间 | 事件 |
|------|------|
| — | 道法少女逐渐恢复数量 |
| 1590年 | 道域巅峰道法少女彻底解决异界当前所有的终焉灾兽。[[天何]]、[[天钧]]又一次暂时下线 |
| 1598年 | [[天烛]]前往例行百年一次的其他世界，寻找拯救世界的办法 |
| — | [[清止]]（天道道法少女）于异界清理其他相对较强灾兽 |
| 1600年 | 本界诞生伪终焉灾兽。[[天姝]]前往处理，[[天烛]]从其他世界赶回，[[清止]]也快速赶来，最后三位一起迅速将其消灭 |

### 1600年·四象小队事件
- 四象小队（法理境）用四象大阵消灭一只苍渊灾兽后，被空间风暴卷入其他世界
- [[天烛]]到达时，仅仅只剩突破道域境的[[龙|青龙]]活了下来
- 出于“鸡蛋不能放在一个篮子里”与复仇考虑，将这个异界作为**第二方舟**

### 中期结束标志
- **1600年**：[[清止]]与[[天烛]]、[[天姝]]的道域复合成为总部“[[百花阆]]”
- 百花阆连接三界
- 道法少女开始**系统化管理**

---

## 五、后期
### 事件
二战后增加诱导对面伤害道法少女然后直接击杀

### 结束标志
- **2008年**：[[灵明]]突破道域巅峰，用自己的能力将“人类无法被正确认知灾兽与道法少女”绕过
- **人类和道法少女开始合作**

---

## 六、大后期

### 关键事件

| 时间 | 事件 |
|------|------|
| 2010年 | “[[永世之痛]]”灾兽诞生，人类和道法少女第一次共同对抗全球性灾难。[[天钧]]与[[天何]]又一次暂时下线。[[天巧]]于战后突破道域巅峰，世界一共有七位道域巅峰道法少女 |
| 2011年 | [[天巧]]、[[天姝]]、[[山河]]联手创造了“[[灾难抑制器]]” |
| 2018年 | [[天巧]]、[[天何]]、[[天姝]]联手创造了“[[转爻器]]”，开创了四代“转爻器转爻”方式 |

### 大后期结束标志
- **2018年**：四代转爻器体系确立

---

## 七、末期

### 特征
- 人类和道法少女共同努力、生活

### 末期结束标志
- **2043年**：道域巅峰道法少女强制所有普通人和非道域巅峰道法少女前往异界

### 第二时期终点
- **2043年**：
  - 七位道域巅峰道法少女中，**四位彻底死亡**
  - 三位突破救世境
  - 三位救世境牺牲重大代价，将**永恒灾兽**扼杀

---

## 两大时期总览

| 时期   | 起始        | 结束       | 核心变化                |
| ---- | --------- | -------- | ------------------- |
| 第一时期 | 七万年前      | 公元前1177年 | 道法少女诞生，人类无法觉醒       |
| 第二时期 | 公元前1177年后 | 2043年    | 人类可觉醒，体系建立、制度化、最终决战 |
