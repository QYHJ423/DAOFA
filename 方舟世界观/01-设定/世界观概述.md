# 方舟世界观概述

## 背景
永恒之战后，原本的世界已无法生存。人们与道法少女只能前往曾经战斗的前线——两个曾被灾兽占领的异世界宇宙，如今被称为**方舟**。

- **时间演化**：公元二零四三年为方舟元年。

## 生存现状
- 每座城市都由道域境道法少女守护
- 城中的[[灾难抑制器]]由[[天姝]]一人提供所有能源
- 文明道法少女死亡产生的特殊灾难已被解决
- 但是两个方舟的道灵以及转爻器也[无法得到补充](方舟时期的觉醒与穿越资源)
 - 道灵现在在非必要情况下禁止参与战斗。
- 总部变化：
 - 只能通过“空印龙缀”进入。
 - 依旧连接三界。
 - 特殊设施：
  - 百花苑：因比较特殊保存完整。
  - 问道殿：只剩下“演武场”。
  - 其余都破损不堪。

## 核心特征
| 维度   | 状态                   |
| ---- | -------------------- |
| 地点   | 两大异界成为新家园            |
| 最高战力 | S级（道域）               |
| 世界状态 | 本界已无法生存，全员迁入异界       |
| 文明阶段 | 重建与存续，在废墟上重建文明       |
| 纪年方式 | 方舟纪年法。以公元二零四三年为方舟元年。 |
