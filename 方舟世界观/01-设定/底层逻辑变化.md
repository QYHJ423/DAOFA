# 底层逻辑变化

## 与主世界（现代篇）对比

| 维度       | 现代篇      | 方舟世界        |
| -------- | -------- | ----------- |
| **最高战力** | 救世境存在    | 最高仅道域境      |
| **世界状态** | 本界尚可生存   | 本界已无法生存     |
| **能源来源** | 多位道域巅峰提供 | 仅[[天姝]]一人提供 |
| **特殊灾难** | 存在       | 已被解决        |
| **方舟定位** | 避难所（未启用） | 唯一的家园       |
| **文明阶段** | 守土抗战     | 重建与存续       |

## 方舟的普通人

### 一、身体异变

### 灾难型异界
- 人们在一两代后出现了**兽人化**
- 并出现了一种**修炼体系**
- **猜测**：向灾难型异界的原本生物靠近了

### 污染型异界
- 人们在进入后便有异样
- 并开发了一种**修炼体系**
- **猜测**：这是这世界原本的特点

---

### 二、科技变化

### 落后
- 由于转移的匆忙
- 方舟不断出现的灾兽
- 各种原料的缺失

导致科技**严重落后**于本界时期。

### 发展
- 由于特殊灾难的消失
- 普通人与道法少女一起开发了不少可以用于**击杀灾兽的道具**
- 但威力有限
- 算是拥有了**补刀的能力**
