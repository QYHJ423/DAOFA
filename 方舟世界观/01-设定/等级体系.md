# 方舟世界等级体系

## 概述
永恒之战后，SS级（救世）已不存在于世。方舟世界的最高战力为S级（道域）。

## 道法少女等级

| 等级  | 名称   | 说明              |
| --- | ---- | --------------- |
| S+  | 道域化境 | 道域有独立世界         |
| S   | 道域   | 开道之域，道域初显       |
| A   | 法理   | 道出法理，获得新形态      |
| B   | 道仪   | 与道合仪            |
| C   | 爻变   | 行道之权，践法之能；全方位增强 |
| D   | 爻衡   | 熟练使用基础能力        |
| E   | 爻动   | 刚觉醒，能使用道法但不稳定   |

## 灾兽等级

| 等级 | 名称 | 范围 |
|------|------|------|

| A | 破灭 | 省级 |

| C | 崩坏 | 县级 |
| D | 动荡 | 乡镇级 |

## 与主世界对比

| 等级  | 主世界（现代）      | 方舟世界   |
| --- | ------------ | ------ |
| SSS | 存在（永恒灾兽）     | 已无     |
| SS  | 存在（天钧、天姝、天巧） | 已无     |
| S+  | 存在           | 存在（最高） |
| S   | 存在           | 存在     |
