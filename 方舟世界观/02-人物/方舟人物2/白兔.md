## 道法

### 月相轮转（被动）
月相不断变化（裙摆的月相也随之变化）：
> 新月 → 弯月 → 满月 → 弯月 → 新月 → ……

不同月相下，可使用的道法不同。

---

### 新月状态（垂耳）
| 道法 | 效果 |
|------|------|
| **捣药** | 使用能量制作各种效果的、可以短时间储存的玄霜 |
| **采月** | 收集各种能量作为药材 |
| **月食** | 隐身、存在感降低 |
| **月障** | 护盾；用月轮可以吸收攻击 |

---

### 弯月状态（半垂耳）
| 道法 | 效果 |
|------|------|
| **月隐** | 存在感降低 |
| **乌飞兔走** | 加快自己的速度 |
| **玉杵·捣毁（被动）** | 破甲 |
| **霜月流光** | 汇聚能量，射出众多月矢 |
| **坠兔收光** | 玉杵化箭，射出‘捣毁’一箭 |

---

### 满月状态（竖耳，法理境）
月轮重新化轮，与玉杵组合为**玉兔月杖**。月轮非常锋利。

| 道法 | 效果 |
|------|------|
| **狡兔三窝** | 用玉兔月杖触碰耳朵，而后消失，在合适位置重新出现（预设位置） |
| **蟾宫折枝** | 吸收所有玄霜，自己和兔子都进入‘月兔’状态（全方面强化） |
| **兔满为患** | 用玉兔月杖召唤兔子 |
| **太阴潮** | 释放持续性攻击 |
| **弦月切** | 一道月弧 |
| **月临** | 用月亮砸向敌人 |
