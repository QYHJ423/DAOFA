- **身高**：149cm
- **发型**：螺鬓，头戴一顶巨大的圆形银饰帽，周围缀满银泡、银链和红色丝穗，走动时摇曳生辉，红色丝穗垂落在脸颊两侧

- **上衣**：以黑色为底，领口、袖口、衣襟镶满粉红的刺绣花边，图案多为几何纹

- **胸饰**：胸前挂多层银牌、银锁
- **手饰**：手上戴银镯，走起来有清脆的声音
- **下装**：黑色长裤以及绑腿
- **臂刃**：袖内双臂绑有臂刃，内侧白色，外侧黑色

## 道域

### 讙头国度
**形象**：一个冰雪国度

### 道域效果
| 效果 | 说明 |
|------|------|
| **讙翼** | 道域中所有队友身法变得敏捷，且行动速度变快 |
| **渔猎** | 标记所有敌人，对其造成伤害增加 |
| **极地** | 队友可以在极端情况下依旧可以保证状态 |
| **讙民** | 有很多小帝欢，有的使用长鼓，有的使用双刃 |
| **咕咕嘎嘎** | 道域中，可以选择将打败的同级及以下的敌人同化为讙民（失败后会被驱除道域，并无法使用长鼓数天） |

## 道法

### 瑶族长鼓

| 道法 | 效果 |
|------|------|
| **霜籁·瑶舞（被动）** | 长鼓配合舞蹈施法，才有效果 |
| **霜籁·帝欢** | 手掌和竹片同时敲击鼓面，凝固周围的时空 |
| **霜鼓·寒潮** | 手掌敲击鼓边，对周围造成伤害、减速 |
| **霜鼓·暖流** | 手掌轻击鼓面，范围内队友得到恢复 |
| **霜鼓·冰裂** | 手掌重击鼓面，造成空间碎裂 |
| **籁鼓·断帛** | 竹片敲击鼓边，造成密集的声波攻击，无视防御 |
| **籁鼓·彻骨** | 竹片敲击鼓面，声波入体打断敌人的施法与恢复 |

### 杖翼双刃

| 道法 | 效果 |
|------|------|
| **滑步（被动）** | 身法轻盈，加速 |
| **破水** | 突击 |
| **迴流** | 急停、改变方向 |
| **霜潜** | 隐身 |
| **跃冰** | 从隐身中解除，造成更强的伤害 |
