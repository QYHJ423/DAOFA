# 道法少女·天启（卜芝）

## 基础信息
- **道号**：天启
- **本名**：卜芝
- **身份**：[[方舟世界观/02-人物/方舟人物1/海晏|海晏]]弟子
- **等级**：道域境（可突破道域巅峰）


## 外貌特征
- **身高**：157cm
- **发型**：银发双马尾
- **眼**：时常闭着眼睛，右眼下方有一颗水滴状泪痣
- **服饰**：绣有蓍草与小冠花的淡金色广袖流仙裙
- **披帛**：粉白色透明披帛
- **足部**：裸足


## 特殊情况
- **五感缺失**：没有视觉、听觉、声音、味觉、嗅觉
- **感知方式**：依靠触觉与权能获取信息
- **表达方式**：依靠启示录、肢体语言、传音
- **觉醒前状态**：半植物人

## 性格特点
- **喜欢出去玩**：最好是有同伴或师傅陪着
- 但师傅总是找[[方舟世界观/02-人物/方舟人物1/蛊仙|蛊仙]]，所以就经常用雷往师傅旁边批（提醒师傅陪自己）


## 权能
天启


## 法理（法理境）

- **天罚铃**


## 道域

### 天道酬勤
随着时间不断由空白慢慢变成第一次想象的世界。

### 道域效果
| 效果    | 说明                   |
| ----- | -------------------- |
| **空** | 剥夺道域中除自己以外的所有五感与语言   |
| **启** | 自己慢慢补全五感并加强感知，最后获得语言 |
| **明** | 一人得道，鸡犬升天（共享增益）      |
