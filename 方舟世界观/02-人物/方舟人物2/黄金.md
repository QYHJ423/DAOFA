# 道法少女·黄金（奇甜甜）

## 基础信息
- **道号**：黄金
- **本名**：奇甜甜
- **成为道法少女时间**：1988年
- **身份**：[[方舟世界观/02-人物/方舟人物1/山河|山河]]弟子
- **等级**：道域境（20年突破）（可突破道域巅峰）

---

## 外貌特征
- **身高**：145cm
- **发型**：银白长发在脑后编成两股粗辫，辫梢各系三枚金铃，垂至腰际
- **兽耳**：一对毛茸茸的狼耳朵
- **抹额**：额前戴一条白貂尾抹额，正中嵌一枚蓝松石
- **上装**：月白交领长袍，右衽，窄袖，袖口与领口镶一圈青灰貂毛
- **腰带**：腰间束一条金色宽带，带扣是马首形铜饰
- **挂饰**：左侧挂一只短角弓（天弓未展开时的形态）
- **下装**：蓝地金纹的宽摆长裙，裙面绣满行云与奔马的暗纹
- **尾部**：大尾巴从裙底探出
- **足部**：白皮长靴，靴筒上缘露出一圈绒边

---

## 性格特点
活泼好动，游玩天下。

**补充**：是**最容易在战斗中碰到的道域境道法少女**。

## 权能
长生天

## 法理（法理境）
- **天弓**
- **苏鲁锭**

## 道域

### 长生天际
**形象**：无尽草原

### 道域效果
| 效果 | 说明 |
|------|------|
| **长生庇佑** | 获得‘长生天的加护’，强化精神与意志，速度加快，伤势缓慢恢复，能量不会枯竭 |
| **天意裁决** | 压制敌人 |
| **非天之谜** | 敌人失去方向感 |
| **天命** | 威慑力加强、攻击必中、召唤物增强 |

---

## 道法

### 基础道法
| 道法 | 效果 |
|------|------|
| **牧** | 召唤狼群、猎鹰、战马等 |
| **骑兵（被动）** | 骑着战马时速度与战斗力大幅度提升 |
| **狩猎（被动）** | 狼群和猎鹰与自己共享视野 |
| **隐** | 降低自身及召唤物的存在感 |
| **猎** | 眼睛变红，锁定目标，对其伤害进行叠加且敌人在自己眼里无处遁形（切换目标即重置） |
| **长生牧歌** | 召唤羊群对友方进行治疗 |

### 法理技：天弓
| 道法 | 效果 |
|------|------|
| **长生（被动）** | 箭矢命中敌人前不会消失 |
| **天弓·星落** | 一箭射向天空，化作箭雨落下 |
| **天弓·白尾** | 消耗目标箭矢，直接降临到箭矢的位置 |
| **天弓·贯日** | 蓄力后，打出极强一击 |
| **天弓·获归** | 射出一箭直接命中目标 |

### 法理技：苏鲁锭
| 道法         | 效果                    |
| ---------- | --------------------- |
| **天意（被动）** | 被命中就会被‘天意’压制          |
| **游牧之誓**   | 苏鲁锭展开旗帜，范围内获得‘长生天的加护’ |
| **天赐**     | 将苏鲁锭扔出，贯穿路径敌人         |

### 组合技
| 道法 | 效果 |
|------|------|
| **狼狩阵** | 将天弓与苏鲁锭吸收，所有的狼群与箭矢化作黄金模样进行狩猎 |

### 道域巅峰技
| 道法           | 效果               |
| ------------ | ---------------- |
| **天地为牧（被动）** | 所有被击败的皆入我的管辖一段时间 |
