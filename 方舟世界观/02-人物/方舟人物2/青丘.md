# 道法少女·青丘（有狐卿）

## 基础信息
- **道号**：青丘
- **本名**：有狐卿
- **成为道法少女时间**：1981年
- **身份**：[[方舟世界观/02-人物/方舟人物1/山河|山河]]弟子
- **等级**：道域境（17年突破）（可突破道域巅峰）

## 道域

### 青丘幻界·涂山
**形象**：涂山（传说中九尾狐的故地）

### 道域效果
| 效果 | 说明 |
|------|------|
| **青丘唤灵** | 召唤一只九尾狐虚影和数只小狐狸虚影进行战斗 |
| **狐火引路** | 狐火会自动延伸到道域里面的所有生物身上 |
| **涂山氏** | 庇佑，分配气运 |

## 法理技

### 九灵尾扇
| 道法 | 效果 |
|------|------|
| **九灵幻阵** | 阵法里有狐火时，将会让狐火四处飘荡，但阵里面的人看狐火就在原位没有动 |
| **九灵炎阵** | 一次性剥夺所有狐火，以及狐火燃烧的气运 |

### 青丘剑
| 道法 | 效果 |
|------|------|
| **灼灼其华（被动）** | 以血饲剑（受伤也算），不断强化 |
| **礼尚往来（被动）** | 吸收防御下来的攻击进行反击 |
| **剑阵·仁民爱物** | 防御（以青丘剑为核心，以九灵尾扇为辅） |
| **赤地千里** | 一剑既出，赤地千里 |
| **大道之行** | 将九灵炎阵燃烧的气运全部吸收，砍出一剑 |

### 道域巅峰技
| 道法         | 效果                               |
| ---------- | -------------------------------- |
| **九尾（被动）** | 获得完整的九尾之力，变成白色。气运影响不再依靠狐火，言谈举止即可 |
