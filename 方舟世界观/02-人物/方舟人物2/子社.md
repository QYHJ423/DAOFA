# 道法少女·子社

## 基础信息
- **道号**：子社
- **本名**：商淑
- **身份**：[[方舟世界观/02-人物/方舟人物1/山河|山河]]弟子
- **等级**：道域境（S级）
- **成为道法少女时间**：1440年
- **突破道域境时间**：121年后（约1561年）

---

## 外貌特征
- **身高**：141cm
- **发型**：灰棕色短发，发梢渐变银灰，银簪固定，两侧鬓角略长
- **瞳色**：暗红色
- **兽耳**：一对圆耳从头发中探出，内耳粉嫩，半竖立，会微微转动
- **上装**：靛蓝色右衽短衣，窄袖，袖口和领口绣有暗金的几何纹样
- **围腰**：深色绣花围腰，系于腰间，垂至膝下，边缘缀有细银链
- **下装**：深靛蓝百褶短裙
- **绑腿**：深蓝色绑腿，从脚踝缠到小腿肚，束紧裤脚
- **腰带**：细银环腰带，下垂几根银链，行动时却没有响声
- **足部**：短靴，行动无声
- **尾部**：后腰围腰处留一道纵向开口，尾巴从中伸出，末端匕首在裙摆下沿若隐若现

## 道域

### 子时夜半
**形象**：子时的夜晚

### 道域效果
| 效果 | 说明 |
|------|------|
| **子神时刻** | 道域中只有子时（可被“子神裁断”逐渐裁短子时的时间） |
| **社君庇佑** | 负面效果一出现就被反转 |
| **万物复苏** | 恢复，道域中时刻出现子鼠 |

---

## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **瘟疫（被动）** | 攻击自带中毒效果，且具有传染性 |
| **子夜突袭（被动）** | 背刺伤害提高 |
| **三刃贯穿（被动）** | 尾刃对已经遭受法理攻击的敌人具有贯穿效果 |
| **子神（被动）（道域境）** | 子时自己各项能力获得提升 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **鼠目寸光** | 在别人眼里，自己非常不起眼 |
| **暗影穿梭** | 快速移动，看起来就像一个黑影穿过 |
| **子鼠成群** | 召唤鼠群 |
| **社君祝福** | 反推弱化、中毒等，将其反转成赐福 |

---

## 法理技

### 夜磨双刃
| 道法 | 效果 |
|------|------|
| **孳生** | 双刃随战斗时间，会累积各种瘟疫 |
| **夜磨子牙** | 双刃摩擦聚积力量 |

### 子鼠剪
| 道法 | 效果 |
|------|------|
| **夜半裁空（被动）** | 物质裁剪 |
| **子夜破芽** | 一剪下去，将其之前所有受到的伤害爆发出来，包括被挡住的（仅限一次） |
| **子神裁断（道域境）** | 剪断一段时间（仅限一次，子时可用） |
| **午夜重置（被动）** | 每次午夜子鼠剪都会重置 |
