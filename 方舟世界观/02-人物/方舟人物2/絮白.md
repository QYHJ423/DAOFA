# 道法少女·絮白（云游迹）

## 基础信息
- **道号**：絮白
- **本名**：云游迹
- **时期**：方舟时期
- **等级**：法理境（A级）
- **所属**：方舟·雪夜小队（唯一幸存者）
- **性格特点**：有些迟钝（超忆症所致），但实际上很聪明，也很随和。对那次任务有PTSD
- **权能**：冰&雪

---

## 背景故事

云游迹原是一支小队里的**情报搜集员**，由于超忆症导致的理解能力差，于是没有道法战斗能力，职责是在队伍前方探查灾兽位置。唯一的依仗是那用于侦察的白色方块——**凝核**。

**2075年**，一次任务中，小队掩护人员撤离时遭灾兽群围攻，除她之外**全队阵亡**。

绝望之下，她回想起了队友平日训练的每一个动作细节。云游迹捡起队友留下的陌刀“雪夜”，凭借记忆里队友挥刀的样子，模仿着和灾兽战斗。

她临死前，在她强大的心愿与凝核一起让云游迹转爻为了道法少女。凝核上的核心是[[转爻器]]。

由于自身力量与精神力特殊的缘故，她刚觉醒的时候就已经来到了**爻变境**。凝核的探查功能也被其特殊理解能力用权能融入她的道法中，也是她其中一个法理，但她还没有完全掌握。而且因为没有从爻衡开始稳固根基，部分道法所需的不仅是法力，也有她的**生命**。（不是跳级的原因。只能说等级卡的尴尬。正好是爻变境拥有自己特色，但又不像道仪境那样像自己身体一样。而且当时没有前辈或者道灵教导。）

## 道仪 & 法理

### 外貌
- **身高**：158cm
- **发型**：浅灰色及肩短发。
- **眼睛**：浅蓝色瞳孔，释放“承影”时会短暂变红。右眼下有一颗泪痣
- **服饰**：上身白色窄袖交领襦衫，带有极淡的冰裂暗纹；外罩冰蓝色对襟半臂。下身配一条八破花间裙，由白-淡灰和白-淡蓝渐变布料拼接，有零星的碎雪暗纹。
- **装饰**：头上偏左有银冠，其上镶嵌天蓝色小方块。腰间左侧有一个深蓝色方形玉佩。
- **特殊**：使用“残念加身”后，坚冰会凝成一件黑-金色明光铠附着于身上。

### 法理
1. **雪夜**：由冰晶凝结成的陌刀，全长170cm，触感极度冰冷。平时以玉佩形式别在腰间。
2. **凝核**：突破时“吸收”的蓝色小方块，以银冠的形式外显。使用相关能力时银冠上的小方块会发光。

## 道法

### 核心机制：承影
释放技能时可选择触发，将记忆实体化增强技能效果，**同步燃烧生命**。
- 未触发时特效为蓝白色
- 触发后为金色夹杂少量红色
- **限制**：每场战斗最多20次。释放20次之后会变得虚弱，无法继续战斗
- **A级强化**：可选择额外增加生命消耗来提升效果强度

---

### 技能列表

| 道法 | 效果 |
|------|------|
| **落痕** | 可以主动探查半径100内的所有声响，并通过记忆判断发出者的方向 |
| **雪落一瞬** | 悄无声息瞬移至范围内（落痕范围或雪昭遗路探查范围，也可以是坚冰为记的标记目标）的目标身后，或是任意安全的地方。有0.1秒冷却 |
| **雪落一瞬·承影** | 瞬移至目标身后时可发动，召唤一个过去的幻影一同攻击。此次技能释放后不会进入冷却 |
| **雪昭遗路** | 凝核升空固定，探查大范围声响。C级150米 / A级300米 |
| **雪昭遗路·承影** | 探查半径+100米，在范围内降雪，使得所有被探测到的目标被冻结，且显示具体位置 |
| **坚冰为记** | 生成5个冰片攻击目标，标记位置并减缓行动 |
| **坚冰为记·承影** | 冰片提升至10枚（额外冰片改变特效），冻结目标（体型过大的目标无法冻结，但能减缓行动） |
| **炽血融冰** | 使用“雪夜”向前方发动范围斩击（半径15米），标记范围内所有灾兽的同时为其留下一道难以愈合的伤口，减缓行动的同时受到的伤害更高 |
| **炽血融冰·承影** | 同时召唤记忆中的幻影武器对斩击区域进行多轮轰炸（幻影的攻击不会伤害自身） |
| **残念加身** | （突破至A级后获得）用坚冰覆盖自身与“雪夜”，攻击减缓目标行动，同时使自身防御提高，造成伤害提高，持续1分钟 |
| **残念加身·承影** | 变得能够短暂预判目标行动，持续时间增至2分钟，每一次攻击都会召唤3个幻影协同攻击 |

---

### 终极技能：承影-雪停之后
- **触发**：无法主动发动，**濒死时自动触发**（突破至A级时自创）
- **效果**：
  - 解放所有记忆，召唤记忆中所有有战斗能力的人物幻影
  - 召唤记忆中所有“对灾兽武器”，攻击凝核范围内所有灾兽
  - 凝核探测范围增至1000米
  - 絮白自身化作幻影，不断攻击范围内灾兽，每次攻击后自动释放承影-雪落一瞬
  - 持续时间为30秒，或凝核范围内没有灾兽后
- **代价**：此后陷入长时间虚弱昏迷，随后以全新姿态苏醒
