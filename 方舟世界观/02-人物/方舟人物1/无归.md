# 道法少女·无归

## 基础信息

- **化名**：吴雨秋（住在城中的时候使用）
- **境界**：道域境
- **性格特点**：沉默寡言，温柔，乐于助人。
- **身份**：由“絮白”、“芯”、“禾秋”三位法理境道法少女融合而成的道法少女。目前以普通人的身份居住在某座城中，也在暗中保护着这座城市。

## 来历

芯与禾秋为了保护使用完终极道法而昏迷的絮白，与苍渊境灾兽战斗至濒死。絮白苏醒后统合了自身记忆、芯的芯片与禾秋种下的“米粒”，还顺便吸收了部分“山河”突破时的文明之力，融合剩下两人成为了“无归”。

## 权能

创生、演化

## 道仪

- **身高**：154cm
- **发型**：黑色长发，长度到背部三分之一，自然飘散。
- **眼睛**：深褐色瞳孔。
- **服饰**：上身暗青色风衣，长度到大腿中间；内穿白色衬衫，衬衫上有淡蓝色冰裂纹。下身黑色工装裤。脚穿一双黑色短靴。
- **装饰**：深蓝色回纹围巾。手上有一块灰黑色电子手表；脖子上一条金色琥珀项链。

## 法理

无。无归的权能可以让她在需要时直接催生出对应物品。物品的精细度取决于投入的生命力。但是除了“残影”，她不能幻化出活物。

## 道域

夕阳下的一片荒地，稀稀疏疏长着一些野草野花，随风摇曳着。远处有群山环绕，山腰处隐隐约约还能看见几座小村落亮起的灯。

**道域效果**：
- **故乡遥望**：无归不需要消耗生命力维持残影的存在。
- **归途夕照**：友方持续恢复伤势，受到的伤害降低，且会分摊到所有友方单位身上。
- **无终念缚**：敌方攻击欲望降低，缓慢流失生命，且被持续标记位置。

## 道法

### 被动：守护之影

无归一般不直接攻击。她的各种动作会产生不同的残影代替她完成攻击、防御等行为。

残影是权能催生出的活物，也视作友方单位。它们会快速判断出战场局势，自主行动。

召唤残影不需要消耗生命力，但是维持残影需要持续消耗。如果不维持残影，则其会在动作完成后消失。

### 道法列表

| 名称 | 效果 |
|---|---|
| 护住被欺凌者的臂膊 | 标记友方单位。这些单位受到攻击的时候，会短暂出现一个残影挡下这次攻击，并发动反击。 |
| 守在手术台边的身影 | 让残影治疗友方，且使治疗目标两分钟内所受的所有伤害延迟到时间结束后生效。 |
| 挡下倒塌房梁的背脊 | 转移友方身上的负面状态至自身。自身消化这些状态，并转换为残影攻击敌人。 |
| 追逐着嫌疑人的双腿 | 友方获得加速。同时召唤残影追踪、束缚敌人行动。 |
| 巡逻边境留下的足迹 | 划定一条敌人无法穿越的“边界”，召唤残影守护界内的友方。**道域**内使用会增强道域效果。|
| 维护四方和平的人们 | 残影的攻击力与反应速度大幅增强，在道域外三分钟内也可以不消耗生命力持续存在。**道域**内使用则会同时增强其余友方单位。 |

## 终极道法：「我们的身后，是万家灯火！」

召唤残影保护所有非残影友方单位，随后召回场上剩余的所有残影。

消耗自身生命力至最后一点（道法结束前不会耗尽），凝结出一把长剑和尽可能多的残影，率领它们一起攻击敌人。每次攻击会使一道残影消散，同时强化长剑的攻击。

可主动关闭，或残影消耗完毕自动关闭。
