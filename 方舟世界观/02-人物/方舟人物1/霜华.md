# 道法少女·霜华

## 基础信息
- **本名**：白曦月
- **境界**：道域境（可突破道域巅峰）
- **身份**：[[天巧]]妹妹，方舟守护者之一
- **师承**：[[方舟世界观/02-人物/方舟人物1/彼岸|彼岸]]

## 道仪
棕色单马尾，身高158cm，蓝为主金紫为辅的军装风格服饰，扣子为霜形，臂章有雪花与闪电纹路，下半身为百褶裙。

## 权能
**寂灭**——（形象是冰雷）（效果类似量子潮汐原理）

## 法理
军刀与枪

## 道域
- **道域境**：寂灭雷域·霜满天——处处飘着雪花
 - 敌人触碰到雪花就会在无声中消散
 - 雪花可以飘到道域以外。
- **道域巅峰**：寂灭雷域·命无寂——处处飘着雪花，还有不断流窜的雷电
 - 敌人触碰到雪花或闪电就会在无声中消散
 - 抹除我方死亡概念，简单的死亡无法达成。
## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **寂灭之息（被动）** | 行动无声无息 |
| **无声消逝（被动）** | 攻击具备极强的穿透，不会产生爆炸与巨响，直接使击中的目标区域无声地消失 |
| **抹除（法理境被动）** | 随着攻击的强度，慢慢剥夺敌人的部分存在 |

### 主动技能
| 道法            | 效果                             |
| ------------- | ------------------------------ |
| **瞬雷**        | 抹除沿途过程，直接到达目的地                 |
| **生命无寂（道域境）** | 以寂灭之力抵挡死亡，保护队友不被死亡彻底吞噬，为治疗赢得时间 |

### 枪（法理）
| 道法 | 效果 |
|------|------|
| **绝对零度** | 打出如黑色闪电般的一击，击中目标后停滞其能量运转，做到沉默与选择行动 |
| **雷霆万钧** | 寂灭沿途过程，直接打击敌人，将敌人命中部分寂灭掉，并从命中部分延伸出去，慢慢寂灭掉其他部位 |
| **死星** | 极致的穿透力，可以轻易破除敌人防御，打出空洞 |
| **凝滞之境** | 打出一个特殊立场，可以削减能量，并将范围内的事物固态化成‘冰块’ |

### 剑（法理）
| 道法       | 效果                                |
| -------- | --------------------------------- |
| **碎冰之音** | 将‘冰块’打碎，只听一声脆响，化作雪花消失             |
| **静默斩**  | 没有任何过程，直接斩出无视防御一击                 |
| **电光一闪** | 化作白光穿过敌人，寂灭如同闪电一般在敌人身体里流窜，使敌人身体消失 |
