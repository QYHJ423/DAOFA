### 特殊的收徒礼物：古枝项链
天巧将一片裙甲化作一个古枝项链，送与银杏当收徒的礼物。
- 天巧把自己的一部分化作项链送给了银杏。
- 成为了银杏道仪的一部分，**完全属于银杏**。
- 项链不具备天巧的创灭效果，仅仅是加强了银杏的天赋、能力、身体素质等等基础。

## 道域：古枝庭院·岁月长河
一株参天银杏立于庭院中央，落叶铺地，枝干虬结如龙。庭院边界模糊，随落叶飘散而延展。一条浅溪绕树一圈穿过，溪水清澈见底，水中倒映的却不是当下——是过去与未来的片段，流速随银杏心意快慢。

| 效果 | 说明 |
|------|------|
| **永世长存** | 自身存在于道域中的任何时间，但同一时间只有一个 |
| **落叶归根** | 赋予队友落空的攻击必中，但必中的时间不确定 |
| **荣华富贵** | 随机为队友添加一个她以前获得过的增幅，会平衡到银杏所能提供的强度 |
| **枯朽不存** | 锁定敌人的削弱，并随机增加一个敌人以前获得过的减益，同样会平衡强度 |
| **永恒岁月（道域巅峰）** | 打捞过去的岁月中的状态、攻击让其在现在生效 |

## 道法

### 核心机制：枯荣（被动）
受到伤害时，会有银杏为自己格挡，远超自身的无法格挡。
银杏成功格挡的会将格挡受到的伤害，**一半转化为‘枯’，一半转化为‘荣’**。
- 根据情况在0～1秒中，将转化为‘枯’的部分，复制一份‘枯’，两份的‘枯’即为自身受到的伤害。
- 转化为‘荣’的部分，将消耗生命复制一份‘荣’，两份‘荣’的部分将在后续化作缓慢的治疗。

### 被动技能
| 道法 | 效果 |
|------|------|
| **脉络（被动）** | 感知一定范围的能量流动，看破伪装，寻找弱点 |
| **枯木长存（被动）** | 生命减弱就会增强自身全属性，且生命将越来越顽强 |
| **孑遗（被动）** | 受到致命伤不会直接死亡，生命力迅速减弱的同时无法移动 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **折枝** | 对自己造成伤害，并使强化自身法理 |
| **一叶知秋** | 消耗产生的‘荣’强化自身，使自身行动快于周围正常时间 |
| **金枝玉叶** | 飞舞古枝剑，消耗产生的‘枯’形成金色叶片剑气 |
| **龙蟠虬结** | 同时使用产生的枯荣，控制敌人 |
| **长生果** | 使用产生的剩余的‘荣’将其化作一个白色的果子，可用作治疗与净化 |
| **落叶归尘** | 释放自身产生‘荣’释放大片银杏叶，进行大范围解控 |
| **朽木不折** | 可以使用自身产生的‘枯’格挡伤害 |
| **再焕一新** | 每隔一段时间，可以将受到的枯荣重置消耗，产生的不会；并重置自身其他状态（时间与实力有关） |
| **阵法·天地黄** | 重置消耗的受伤的枯荣，与自身产生使用的枯荣相等时，可以使周围产生漫天黄叶进行攻击，时间越长越锋利 |

### 法理境技能
| 道法 | 效果 |
|------|------|
| **万古一脉·千古长青（法理境）** | 打开自身岁月枷锁，自身不受拘束，剔除枯荣限制；自身能力效果翻倍。结束后自身陷入‘假死’，需要多次‘再焕一新’才能苏醒。（道域巅峰不受限制） |

### 道域巅峰技能
| 道法 | 效果 |
|------|------|
| **不死甘木** | 只要目标没死，就能让其完全恢复 |
