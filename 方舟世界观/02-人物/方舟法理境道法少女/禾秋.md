# 道法少女·禾秋（黎明）

## 基础信息
- **道号**：禾秋
- **本名**：黎明
- **身份**：蛊仙弟子；絮白战友等
- **等级**：法理境（A级）

---

## 外貌与道仪

### 基础道仪（161cm）
- **发型**：浅棕长发编成双麻花辫，系麦穗发绳与白色稻花饰
- **瞳色**：琥珀色眼瞳
- **服饰**：白底青绿渐变交领短袄，下着及膝的金色麦浪百褶短裙
- **配饰**：腰挂竹篓，腕踝戴草籽链
- **足部**：裸足

### 蜕变道仪（法理境，生命力极盛时可用，158cm）
- **发型**：银白渐变金黄长发用谷穗高束
- **瞳色**：黄金重瞳
- **服饰**：身着白底金纹百褶裙，外罩禾苗青披肩
- **足部**：赤足踩地会浮现淡金麦穗阵纹
- **配饰**：腰佩内含金米的翡翠手环

## 道法

| 道法 | 效果 |
|------|------|
| **丈量（被动）** | 可以感受能量的流动，感知队友与敌人的状态 |
| **折腰** | 对敌人施加重力，限制敌人行动；强化友方意志，免疫恐惧和精神污染 |
| **皆苦** | 消耗自己生命力，在敌人身上种下草种，使敌人能量枯萎 |
| **春种** | 消耗生命力化作种子，在队友身上化作金色麦穗，持续提供恢复和护盾 |
| **施肥** | 在敌人身上种下种子，种子会飞速吸收敌人法力生成金色麦穗 |
| **秋收** | 回收麦穗恢复自身生命力 |

---

## 蜕变道仪专属道法

| 道法 | 效果 |
|------|------|
| **丈量（被动）** | 可以感受能量的流动，生命感知，队友与敌人的状态感知 |
| **家无担石** | 生命力低到一定程度后变回初始道仪 |
| **旦** | 使用自己的生命力换取价值，无法超额使用。<br>①用自己的生命力一比一给队友买取治疗、状态；<br>②用自己的生命力二比一买取敌人的攻击从而化解；<br>③买取敌人生命从而绝杀（一般不值，常作用于快死但难以击杀的） |
