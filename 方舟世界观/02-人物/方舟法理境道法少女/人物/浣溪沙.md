# 道法少女·浣溪沙（倪佩佩）

## 基础信息
- **道号**：浣溪沙
- **本名**：倪佩佩
- **觉醒成为道法少女的时间**：方舟元年
- **身份**：金丝雀弟子
- **等级**：法理境（A级）

---

## 性格
懒散；耐心；爱钓鱼；佛系无所谓，个别方向自尊心强；薛定谔的暴脾气。

---

## 外貌与道仪

### 基础道仪（151cm）
- **发型**：深棕长发随意扎成低马尾，头戴微旧竹编斗笠
- **瞳色**：茶色眼瞳，死鱼眼，无精打采
- **服饰**：深绿防水冲锋衣与黑色工装短裤
- **足部**：高筒涉水靴
- **配饰**：腰间挂着铁盒

### 超频雷电道仪（法理境，151cm）
- **发型**：银白色低马尾
- **瞳色**：血红色眼瞳，死鱼眼，但眼冒电流，一点都不无精打采
- **服饰**：窄袖玄黑色交领短打，衣襟与袖口用银线绣着雷兽图腾。腰间扎着暗红色的宽幅束腰
- **配饰**：挂着由雷击木雕刻的鱼篓
- **足部**：赤裸双足悬空，脚踝处缠绕着噼啪作响的蓝紫色雷光
- **手部**：双手带着由纯粹雷电凝结而成的半臂长手套
- **副作用**：消耗巨大，解除后还有漏电副作用

## 道法

| 道法 | 效果 |
|------|------|
| **抛竿（被动）** | 攻击带有延伸伤害，额外攻击到其他敌人；如果打空或者没有其他敌人，则延伸伤害会让敌人短暂‘上钩’，短暂限制一定的敌人行动 |
| **提竿（被动）** | 对虚弱的敌人造成的伤害增加 |
| **打窝** | 向指定区域释放具有吸引力的特殊能量，且具有一定的扰乱精神的效果 |
| **甩大鞭** | 大范围横扫造成伤害并击退附近敌人 |
| **溜鱼** | 直接挂上一个敌人，控住敌人行动，并持续消耗对方体力、法力 |
| **切线** | 恢复精神并治疗 |
| **参军** | 把队友钓过来，帮助队友脱离 |

---

## 雷电道仪专属道法

| 道法 | 效果 |
|------|------|
| **敢空军试试（被动）** | 攻击会标记‘雷印’——带有雷电和麻痹 |
| **我说一个都跑不了** | 对附近释放强大电流 |
| **想溜** | 加速，攻击带有吸附 |
| **高压电击** | 抓住敌人，往身体内不断地灌注电流 |
| **抄网** | 形成巨大雷电网，网住一定范围的敌人 |
| **今天天气真好** | 从天空降下雷暴 |
| **绝不空手而归** | 引爆所有敌人身上的‘雷印’，造成爆裂伤害 |
