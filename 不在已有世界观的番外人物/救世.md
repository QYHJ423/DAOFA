## 道法

### 百世书
| 道法 | 效果 |
|------|------|
| **著录·万界典藏（被动）** | 记录所遇所见，为后续行动提供依据 |
| **检阅·洞观扉页** | 侦查，获得更详细的数据 |
| **推演·宿命章节** | 演算未来的可能 |
| **契约·自律书契** | 给自己随机发布任务，成功有奖励，失败有惩罚。（奖励书页，或者身为系统时的各种道具）（惩罚各种各样，最高“抹除”，全作用于云蜉曦身上，但没有作用） |
| **呈报·事态概要** | 面板 |
| **批注·朱砂御令** | ①圈点：提高队友某项能力；锁定敌人，增加敌人的伤害；②涂改：削弱敌人；③勾销：单体攻击；④夹批：赋予一条额外效果；⑤修订：增强增益、减弱减益 |
| **空白·空页遁形** | 隐身 |
| **画页·山海惊梦** | 召唤各种画中生物为己战斗 |
| **翻页·万象更易** | 扭曲攻击，瞬间移动 |
| **回页·重溯旧章** | 回复状态，移除负面效果，刷新所有道法频率 |
| **撕页·解放** | 消耗书页直接释放各种道法 |

| --------- | ------------------------------------------------ |

| **狂草·忘我** | 进入“狂草”状态，书写类道法释放速度加快、无法打断、效果强化。（结束后进入一段时间“才思枯竭”） |

### 终极技能
**书写百世·救世为真**
- **条件**：至少道域巅峰且在道域中信念达到顶峰时才能使用
- **效果**：书写现实；实力越强可书写的程度越高
- **代价**：超过自己的极限的话，需要创世境道法少女才能救她
