# 道法少女·霞云（李裳清）

> **注**：本角色为番外人物，与本世界观主线无直接关联。

## 基础信息
- **道号**：霞云
- **本名**：李裳清（原名：李长青）
- **特殊身份**：首位变成道法少女的修行者
- **转爻契机**：师傅**云蜉曦**将李长青平行世界已经死亡的自己的因果嫁接到李长青身上，使其可以转爻成为道法少女。

---

## 外貌与道仪
- **身高**：152cm
- **外貌**：黑发黑瞳，剑眉星目
- **服饰**：彩霞仙装，云纹长靴

## 性格
为求大道可以接受各种考验；沉稳坚韧同时愿意冒险；责任心强。

**常说的话**：
> “权当练心了。”

## 日常
1. 修仙者师傅跑出去历练（当甩手掌柜）去了，把宗门交给了霞云。
2. 保护另外平行世界自己的家乡。
3. 给到处惹事的云蜉曦擦屁股。
4. 指导其他师弟师妹等等。
5. 修炼。

## 道域：紫气东来

| 效果 | 说明 |
|------|------|
| **紫气加护** | 获得“祥瑞”效果，自身“气运”大幅度提升。使队友受紫气滋养。状态提升、伤势愈合、负面效果净化。镇压邪祟 |
| **东来之势** | 对敌人造成持续的压迫。自身的速度、威严大幅度提升；攻击具有起始与穿透效果 |
| **云霞同调** | 减少消耗，加强道法效果、施法速度，道域中消耗还可以重复所用 |
| **紫气东来·气贯长虹** | 在云霞剑上刻下符箓，凝聚道域中所有紫气和霞光，打出必杀一击 |
