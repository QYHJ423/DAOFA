## 道域：蝶梦花园
一个有很多蝴蝶的花园。

| 效果 | 说明 |
|------|------|
| **蝴蝶振翅** | 任何人的任何行动都会有蝴蝶相伴 |
| **栩栩然蝴蝶** | 所有的蝴蝶都是全然真实、全然虚假的 |
| **蝶戏游蜂** | 蝴蝶会把人拉进梦境里面 |
| **入梦无痕** | 没有蝴蝶也会不知何时就进入梦境了 |
| **漆园蝴蝶梦** | 每个蝴蝶都有一个梦境；梦境与现实混淆 |

## 道法

### 梦
| 道法 | 效果 |
|------|------|
| **庄生晓梦·两界** | 梦蝶创造一个与敌人相应的世界。那个世界会有一个与其同梦之人。如果敌人扛不住，同梦之人都会慢慢模糊自我 |
| **魂牵梦绕·大梦先决** | 让队友、敌人的努力都会获得成果；队友获得真相 |
| **南柯一梦** | 敌人成长就像南柯一梦，剥夺敌人实力 |
| **黄粱一梦** | 让敌人每次攻击都像黄粱一梦一般 |
| **浮生若梦·同梦连枝** | 强化所有人，选择自己喜欢的梦作为真实 |
| **梦中说梦** | 梦境叠加 |
| **庄周梦蝶（创世）** | 什么是真什么是假？每个人的想法都会形成对应的真正的世界 |
| **蝴蝶一梦** | 让创造的世界消失，与这个世界模糊的敌人也会消失 |

### 蝶
| 道法 | 效果 |
|------|------|
| **韩凭化蝶·蝶化庄生** | 复活人 |
| **蝶起青萍** | 影响扩散。强化能力效果 |
| **牵花引蝶（被动）** | 容易吸引人 |
| **蝶恋花（被动）** | 自身能力曲折难辨，难以被人辨别 |
