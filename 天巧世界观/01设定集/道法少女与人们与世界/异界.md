# 异界

## 异界是什么？
- 异界前期是战场
- 异界后期是被道法少女用作**方舟**的世界——在SSS永恒灾兽诞生前，所有普通人与不到道域巅峰的道法少女迁往此处避难。

## 对于异界的认识
- 在SSS永恒灾兽诞生前，所有普通人与不到道域巅峰的道法少女迁往此处避难。
- 由天烛亲自连通。但是在普通人与低等级道法少女的认知中，两者是突然连接起来的。
- 普通人/道法少女：异界入侵者。
- 之所以让人们认知与人类合作就是为了让他们适应灾兽的存在。
- 2040年初，道域巅峰道法少女向核心成员（道域境和人类高层）同步永恒灾兽信息，然后才开始有部分军队先行前往异界与道法少女一起在异界进行战斗，并适应异界生活；后面慢慢扩大信息同步范围，直到最后一天才进行最后同步。
- 道法少女已经完成了大部分生活地建造，军队过去是先行适应异界战斗与生活。
- 本界代表本宇宙，异界代表其他宇宙。

## 两大异界

两个异界各自有不同的异常。人们在饱受异变侵袭的同时，也在积极寻求利用它们的方法。

### 第一方舟：灾难型异界

**发现时间**：公元前200年

**镇守者**：天何
1. **灾难特点**：超多的非正常自然灾难。
2. **普通人异变特点**——方舟时期
 - **兽人化**：人类在迁入后，经过数代的繁衍，身体逐渐出现了各种动物的特征（如兽耳、尾巴、鳞片等）。
3. **前文明信息**
 - 该界的前文明存在着许多不同的种族，拥有各自的生理特征与生态位。因为实力有限，且无法彻底杀死灾兽，最终灭绝。
4. **普通人修炼方式**——方舟时期
 - 人们发现，身体长出的异变带来了许多特殊的能力（比如夜视，超强力量等，甚至一些超能力）。因此，他们开始探索，并最终摸索出了一套通过强化自身兽化特征，来强化肉体和战斗力的修炼体系。

### 第二方舟：污染型异界

**发现时间**：公元1600年

**镇守者**：天均、清止等

1. **灾难特点**：非正常污染。
 - **污染的侵袭**：该界的环境被严重污染。污染类型可分为**物理污染、精神污染、能量污染**等。道法少女长期下去会因为强烈污染**精神异常、敌我不分**（道域境及以上免疫）。
2.  **普通人异变特点**——方舟时期
 - 人类在迁入后，起初会因为此界污染人们无法离开灾难抑制器的范围，离开灾难抑制器作用范围甚至会立刻污染致死；经过数代的繁衍，人们情况好些，可以离开一定范围一段时间，甚至有人早早就能吸收天地灵气，从而拥有非人的实力，但吸纳此界被污染的天地灵气会导致减寿、失控、走火入魔，常常短命。
3. **前文明信息**
 - 该界前文明是一个修仙世界。但在无法对抗的污染和无法杀死的灾兽的威胁下，前文明最终灭绝。
4. **普通人修炼方式**——方舟时期
 - 在**海晏、蛊仙等多位道法少女**看出了修炼者被污染的本质后，人类在几名道域境道法少女的帮助下积极探索，再不断有人的试错下，最终结合前文明最后改良好的修练法与多位道法少女的协助下，人们终于摸索开发出了一部真正的过滤掉污染利用”天地灵气“进行修炼的法门，但还是无法长期在污染的天地灵气下进行。
  - 多位道法少女并没有直接祛除他们的污染，而是压制污染，保证他们在污染中活着进行修炼、探索发现，进行试错，让多位先驱者一步一步的在多方向进行改善修炼的法门，并传给后来者继续试错。
