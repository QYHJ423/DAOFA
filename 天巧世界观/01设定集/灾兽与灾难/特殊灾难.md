# 特殊灾难

## 文明道法少女死亡的影响
| 死亡数量 | 影响                                     |
| ---- | -------------------------------------- |
| 1位   | 灾兽和道法少女无法被任何形式记录（如：描述、书写、绘画、摄像等；即信息屏障） |
| 2位   | 无法发展道法侧道具（道法无法长期留在物质中，即道法隔绝）           |
| 3位   | 灾兽和道法少女无法被正确认知（会被脑补成合理的东西，即认知屏障）       |
| 4位   | 无法诞生新的道法少女，有复活能力的也无法复活                 |
三位文明道法少女的彻底死亡所产生的文明之力提前使道法少女体系在本世界稳定下来，人类中可以觉醒道法少女
- 注：文明道法少女的诞生是镇压了特殊灾难；所以文明道法少女死亡会引发特殊灾难的出现。

## 延迟探知
- 刚诞生的道法少女和灾兽都无法直接被道法探知；用道法得知他们的存在具有一分钟延后性；只能通过六感（绝对真空期）
