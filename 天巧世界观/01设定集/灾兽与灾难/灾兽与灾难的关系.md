# 灾兽与灾难的关系

## 基本关系
1. **灾兽的出现会带来灾难**：根据灾兽的等级不同，灾难的范围和程度会有不同
2. **灾难也有可能诞生灾兽**
3. **次生灾厄**：灾难（灾兽）会引起次生效果，从而诞生新的灾难（灾兽）
4. **灾兽耦合**：灾兽们可能会耦合在一块变成新的更强灾兽（复活的灾兽产生耦合的概率更大）。

## 不同步情况
| 类型    | 说明                                   | 危害              |
| ----- | ------------------------------------ | --------------- |
| 灾兽先行  | 灾兽先于灾难，灾兽出现必然会带来灾难                   | 级别高的情况下危害大于灾难先行 |
| 灾难先行  | 灾难先于灾兽，由于普通灾难也会诞生灾兽                  | 需要长期有道法少女驻足     |
