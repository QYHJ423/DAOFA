# 道法少女·天麟（翼巧七）

## 基础信息
- **道号**：天麟
- **本名**：翼巧七
- **身份**：**四象小队**全员的弟子
- **成为道法少女时间**：1599年
- **等级**：道域境

---

## 外貌特征
- **身高**：150cm
- **发型**：墨发齐腰
- **特殊**：头顶生一对半透明金红小鹿角
- **瞳色**：琥珀金瞳
- **上衣**：红黄撞色交领短打
- **披风**：金红短披风
- **足部**：赤足，脚踝处环绕着一圈若隐若现的金色鳞片
- **尾部**：身后拖着一条末端如火的细长麟尾
- **特殊**：行走时脚下生微弱祥云

## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **麒麟踏雪（被动）** | 不沾污染。且具有加速、精神恢复 |
| **不履生草（被动）** | 难以被仇视 |
| **万乘之威（被动）** | 降低敌人的攻击欲望，压制敌人行动 |
| **瑞兽之体（被动）** | “气运”加护，且降低周围污染 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **踏云·破灭** | 瞬间加速冲锋，形成强力冲击，身后留下祥云 |
| **麟火·涤荡** | 焚烧灾厄、污染、诅咒、毒素 |
| **千瑞护身** | 召唤金色麒麟虚影抵挡伤害 |
| **五色祥云** | 脚下祥云散开化作泥沙或藤蔓限制敌人 |
| **百兽之角** | 召唤红色麒麟虚影攻击敌人 |

### 法理技
| 道法 | 效果 |
|------|------|
| **西狩麒麟（法理境）** | 用自己的血携带自己的气运哺育他人，具有极强的恢复、强化、气运加持等效果；用得越多效果越好，自己运气也会越差 |
