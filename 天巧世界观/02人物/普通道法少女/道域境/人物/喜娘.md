# 道法少女·喜娘

## 基础信息
- **道号**：喜娘
- **本名**：冬雪琉
- **身份**：[[道法少女/天巧世界观/02人物/普通道法少女/道域境/人物/山河|山河]]弟子
- **等级**：道域境（S级）
- **觉醒成为道法少女时间**：1477年
- **突破道域境时间**：154年后（约1631年）

---

## 道号来源
新年时间，刚通过[[道灵]]转爻一段时间的冬雪琉，经过道灵帮忙，成功带着附近人们等到了道法少女·[[道法少女/天巧世界观/02人物/普通道法少女/道域境/人物/山河|山河]]将灾兽消灭。

以为是妖怪吃人的人们被救下后，结合民间传说，故而把她当做**喜蛛降世**，纷纷称呼她为“喜娘”。

故而将“喜娘”当做道号。

---

## 外貌特征
- **身高**：142cm
- **发型**：银白长发，用一根红绳绾成松髻
- **瞳色**：赤瞳
- **上装**：浅红交领襦裙，外罩红色半臂
- **腰饰**：腰间系一条红色丝绦，垂着一个小小的蜘蛛形坠子
- **足部**：黑色软底布制弓鞋
- **配饰**：手腕上缠着白线，脚踝系着银铃
- **特殊**：走起路来，丝线在身后飘动

## 道域

### 天罗地网

| 效果 | 说明 |
|------|------|
| **天罗** | 白丝从天空垂下，为队友带来庇佑，免疫一定程度的攻击 |
| **地网** | 黑丝从地面升起，敌人的行动、能量流动、空间移动等都受到限制 |
| **盘丝** | 丝线上不断出现喜蛛 |

---

## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **千丝万缕（被动）** | 感知 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **报喜** | 召唤小喜蛛，带来吉兆；帮忙探查、传递信息、攻击敌人 |
| **双喜临门** | 蜘蛛型坠子化作喜娘分身进行战斗 |

### 白丝
| 道法 | 效果 |
|------|------|
| **结网（被动）** | 恢复状态 |
| **封疫（被动）** | 抵挡污染 |
| **喜从天降** | 垂丝，替队友挡下一定程度的致命攻击 |
| **蛛丝护婴** | 织成护盾抵挡伤害 |
| **喜结良缘** | 共享增益，分担伤害 |
| **垂丝续命（一次仅一位）** | 队友或自己濒死时，用蛛丝吊着性命（期间白丝无法使用） |

### 黑丝
| 道法 | 效果 |
|------|------|
| **屠龙（被动）** | 对‘龙’效果更好 |
| **以小博大（被动）** | 敌人越大，效果越好 |
| **龙困浅滩** | 用黑丝束缚敌人行动、能量流动 |
| **龙鳞之隙** | 黑丝攻击敌人防御薄弱处，钻进敌人身体，从内部瓦解敌人 |
| **缠丝** | 用黑丝切割敌人 |
| **收网** | 绞杀敌人 |
