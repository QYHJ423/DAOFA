# 道法少女·光影

## 基础信息
- **本名**：伊晴星/伊虹雨
- **境界**：道域境（24年突破）
- **成为道法少女时间**：1551年
- **身份**：[[天烛]]弟子
- **特殊体质**：一魂双体（无主次之分、无精神分裂一说；两位的互动就是自恋者的自我互动。）
- **性格特点**：
  - 害怕孤独
  - 严重自恋癖
  - 讨厌进行融合
  - **对外**：不娇不媚
  - **对内**：又娇又媚

## 双体特征
- **‘光’伊晴星**：常说体面话
- **‘影’伊虹雨**：常说心里话
- **注**：两位有时候会因为激动或其他原因不小心搞反说的话

## 道域

### 负阴抱阳·环中
天地为昼夜各半。日月异位，光与暗自分明。道域中央悬一虚无之“环”——非日非月，非阴非阳，乃“道枢”。光与影自环中流出。

脚下大地黑白交错。每一步踏下，黑白流转。

### 道域效果
- **光影相伴**：随时进行分合转化
- **阴阳相生**：互相增强对方，融合体现为左脚踩右脚
- **黑白流转**：获得自己最需要的效果
- **太初领域**：任何状态下都拥有‘太初’效果
- **环中·应无穷**：环在阴阳永衡

## 道法

### 光之道法
| 道法 | 效果 |
|------|------|
| **照彻** | 大范围光耀，驱散黑暗、幻象、负面效果，同时带来阴影 |
| **履昼** | 从一片光瞬移到另外一片光 |
| **三阳开** | 三段攻击，第三段达到‘极’。同时触发‘极则反’，自身被阴影笼罩（影可以借用此阴影） |
| **璇玑玉衡** | 短暂预测未来 |
| **大明始终** | 进行一次大耀审判，造成巨大伤害。结束后光明散去只剩阴影 |

### 影之道法
| 道法 | 效果 |
|------|------|
| **玄同** | 潜入任何阴影中，不可选中，移动无声 |
| **履夜** | 从一片阴影中瞬移至另外一片阴影 |
| **三阴起** | 三段攻击，第三段达到‘极’。同时触发‘极则反’，自身被光耀覆盖（光可以借用此光耀） |
| **宵中星虚** | 姐妹二人在光中的影子将会变成自己的助手 |
| **太阴之精** | 30秒内无消耗、无冷却，同时每次攻击都会种下‘太阴之种’。30秒结束后‘太阴之种’将会吸取目标生命力，同时阴影散去只剩光明 |

## 组合技

### 组合技
| 道法         | 效果                                                |
| ---------- | ------------------------------------------------- |
| **皦昧**     | 皦昧：当两位都触发“极则反”后，便可以随时进行一次模糊两位的边界，进行状态、位置等的交换或者平衡。 |
| **半晌（被动）** | 影铳的攻击通过光轮后击中目标可以使敌人视线、时间感知出现问题。                   |

### 光影晷
| 道法 | 效果 |
|------|------|
| **阴阳割昏晓** | 使用光影晷，将敌人化为光影两体，从而削弱敌人个体实力。敌人的光影体互相触碰就会触发‘归墟’。影可以用暗影权能从影体处出现；光用光明权能制造敌人的新影子与影体触碰将对影体造成伤害 |

## 合

### 被动技能
| 道法 | 效果 |
|------|------|
| **太初（被动）** | 光与影从相反方向同时攻击，交汇处触发‘归墟’。造成无视防御的一击 |
| **冲气以为和（被动）** | 当一位受到致命伤害时自动化为一体 |

| 道法        | 效果                      |
| --------- | ----------------------- |
| **大制不割**  | 防御。受到的伤害过多将会召唤四象承伤      |
| **两仪生四象** | 召唤少阴、少阳、太阴、太阳四位光影分身协助作战 |
