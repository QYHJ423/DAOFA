## 道法

| 道法 | 效果 |
|------|------|
| **童心未泯（被动）** | 每天重置卡牌数量 |
| **角色扮演** | 不消耗卡牌直接赋予队友或自己一个身份——医生、护卫、刺客、父母、孩子等等，从而获得对应身份的能力。每个身份都具有两面性，一面增益一面减益，可提前使用卡牌抹除增益或者减益；时间结束才能切换 |
| **翻牌** | 将卡牌扔向目标可以进行身份的快速切换，可以只选择一面 |
| **多重扮演（道仪境被动）** | 可以赋予单人2～4个身份，随实力增强而增加赋予数量 |
| **主角（法理境）** | 通过消耗7个卡牌指定扮演一位自己比较熟悉的人2小时，但只能扮演比自己弱的或者差不多的，无法扮演比自己强的；可以使用其部分能力，熟练度自己练，扮演的角色实力就是自己的实力 |
| **群演** | 消耗12张卡牌，随机召唤一个主角的自己2小时，并同步成现在实力，但熟练度为零 |
