# 道法少女·狸奴（张谂淑）

## 基础信息
- **道号**：狸奴
- **本名**：张谂淑（乳名：怀归）
- **身份**：[[道法少女/天巧世界观/02人物/普通道法少女/道域境/人物/山河|山河]]弟子；张居正族妹
- **等级**：法理境（A级）
- **成为道法少女时间**：1560年

---

## 外貌特征
- **身高**：141cm
- **发型**：黑色长发，低马尾，发尾微翘
- **瞳色**：琥珀色竖瞳
- **上衣**：交领右衽短袄，月白色，袖口绣猫爪纹
- **外罩**：墨绿色比甲
- **下装**：马面裙
- **足部**：软底绣鞋
- **尾部**：身后一条黑色猫尾，尾巴末端系银铃，行动时无声，只有她愿意的才能听得到

---

## 性格
胆大、好学、自信、勤勉刻苦，严于律己、刚毅果决，勇于任事、有强迫症。

---

## 权能
墨

---

## 法理
- **墨卷**（尾巴会无意识地在墨卷上面绘画）

---

## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **九命（被动）** | 气运极高，难以死亡 |
| **夜瞳（被动）** | 夜视、感知、看穿伪装 |
| **狸奴（被动）** | 身轻体柔 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **墨隐** | 隐身 |
| **泼墨（法理境）** | 沾到敌人身上，标记敌人；控制墨形成自己想要的‘卷’（阵法卷除外） |

### 墨卷
需要绘制好才能用。

| 道法 | 效果 |
|------|------|
| **狸奴卷** | 召唤猫群 |
| **金戈卷** | 将绘制的武器召唤出来 |
| **心象卷** | 尾巴会自己画好，将感知到的信息具象化 |
| **山河卷** | 瞬间改变地形，进行干扰 |
| **众生卷** | 绘制人像，用于追踪、伪装、替身 |
| **天时卷** | 改变局部天气 |
| **阵法卷（法理境）** | 临摹的阵法图，具有对应的能力 |
