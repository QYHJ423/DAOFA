# 道法少女·鸢尾花（艾蕾莉丝·德·希里）

## 基础信息
- **道号**：鸢尾花
- **本名**：艾蕾莉丝·德·希里（Eleiris de chiris）
- **成为道法少女的时间**：1799年
- **身份**：子社弟子

---

## 性格
- 温文尔雅，举止得体。
- **守信到近乎固执**，答应的事一定做到。
- 喜欢鸢尾花。
- **喝茶狂魔**：喜欢喝茶，一天不喝浑身难受；喜欢请人喝茶。喝茶的人如果不好好品茶，她会在内心偷偷生气，并想方设法地教会对方怎么品茶。
- 战斗务实，不冒进，信标布好才动手。

---

## 外貌与道仪
- **身高**：166cm（设定中道仪写的是浅紫至蓝紫长发，法理境处又标了166cm，综合来看）
- **发型**：浅紫至蓝紫的长卷发如瀑布垂落
- **头饰**：头戴一顶饰有紫色鸢尾花与黑蕾丝的白色小礼帽
- **服饰**：身穿一袭剪裁得体的淡紫色洛丽塔风连衣长裙，裙摆层叠如绽放的花瓣，领口与袖口点缀着繁复的白色蕾丝花边，腰间系着深色缎带
- **足部**：双腿穿着白色连裤袜，脚踏一双精致的深紫色玛丽珍皮鞋
- **携带物**：手中常握着一把蓝紫色权杖

## 道法

| 道法 | 效果 |
|------|------|
| **鸢尾花印（被动）** | 权杖或者戒指触碰过的目标都会留下鸢尾花信标；鸢尾花能通过信标感知目标的状态、位置 |
| **虹桥连接** | 可以选择信标的目标进行连接，使她们能感知到相互的状态、位置；也可以是单向的 |
| **鸢尾·递传** | 消耗被作用者身上的信标，可以将其受到的攻击/道法效果传递到另一信标上面，同样消耗被传递者身上信标 |
| **鸢尾·远信矢** | 发射鸢尾光矢，命中留下信标 |
| **鸢尾·近信矢** | 通过引导在周围布下大量信标 |
| **鸢尾·指引** | 消耗大量信标作为引导，放置指引，可选择的通过消耗信标将附近拥有信标的目标传送至引导位置 |

### 法理境技能
| 道法 | 效果 |
|------|------|
| **鸢尾·未寄之信（法理境）** | 消耗目标信标，使其受到的攻击、治疗等等储存起来，数秒后生效 |
| **花戒·契约（法理境）** | 通过缔结契约，使契约期间目标一直拥有信标，至多两位 |
| **花戒·收寄** | 可以储存一些东西在花戒里面 |
