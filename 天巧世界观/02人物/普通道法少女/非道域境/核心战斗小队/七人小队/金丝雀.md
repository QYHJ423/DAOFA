## 性格
由于小时候一直被家人控制性的教导，金丝雀一直渴望做自己想做的事。

所以现在**只做自己想做的事**，有点死缠烂打、还超级爱撒娇。

## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **雀鸣（被动）** | 银饰作响，吸引敌人 |

### 御
| 道法 | 效果 |
|------|------|
| **笼中雀（被动）** | 入笼。受到攻击会被‘笼’所保护，具有超高防御，限制自身空间移动 |
| **栅栏（被动）** | 隔离敌人与攻击的靠近，限制自身行动 |
| **巢笼** | 展开金丝笼领域，其中的队友得到休息，获得护盾、恢复、净化 |
| **归巢** | 召唤金丝笼帮队友抵挡伤害 |
| **囚笼** | 可以召唤囚笼困住敌人 |
| **雀困众生** | 可以将一位敌人关押进金丝笼里，同时将囚笼困住的敌人也拉进来；具有极强的防御力，难以被打破；且限制敌人的空间移动 |

### 速（法理境）
| 道法 | 效果 |
|------|------|
| **云中雀（被动）** | 出笼。自身的防御大幅度削弱，但获得超快的速度，雀鸣的吸引置于身后；同时银链连接的金丝笼一同固化当杖使用 |
| **掠影（被动）** | 留下与雀鸣位置相同残影吸引敌人 |
| **破空（被动）** | 打开敌人的防御，对敌人造成贯穿伤害 |
| **雀困众生** | 可以将一位敌人关押进金丝笼里；具有极强的防御力，难以被打破，且限制敌人的空间移动 |
