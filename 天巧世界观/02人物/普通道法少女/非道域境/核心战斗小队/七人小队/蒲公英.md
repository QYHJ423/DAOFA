## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **飞絮（被动）** | 行动时身边会出现蒲公英绒球，任何风吹草动都会影响绒球状态从而进行感知 |
| **絮语（被动）** | 花絮携带声音与信息，实现通信 |
| **风飘絮（被动）** | 身体极轻，行动无声；极容易从他人攻击旁边擦过 |
| **绒球挂坠（被动）** | 花絮挂敌人身上会标记敌人 |

---

### 法理技：花伞
| 道法 | 效果 |
|------|------|
| **花粉（被动）** | 花伞会散落花粉，花粉碰到队友会治疗队友 |
| **开** | 打开花伞，形成护盾抵挡伤害，抵挡伤害时会形成蒲公英绒球 |
| **合** | 收拢花伞，形成长枪，韧性十足；每次攻击都会形成蒲公英绒球 |
| **散** | 伞叶飘落，化作花刃进行远程攻击，并飘落花絮 |

---

### 法理技：蒲公英杖
花伞变化成蒲公英杖（会不断地从杖头飘出蒲公英绒球）

| 道法 | 效果 |
|------|------|
| **域（被动）** | 花絮过多的地方会形成‘絮域’，削弱范围内敌人的感知 |
| **愈** | 用花絮治疗队友 |
| **爆** | 引爆指定区域的花絮，造成范围伤害并形成风压汇聚花絮进行持续爆炸 |
| **飘** | 与完整的蒲公英绒球进行换位，绒球散成花絮 |
| **盾** | 召唤大量蒲公英绒球进行持续抵挡分散伤害，极容易被打散成花絮 |
