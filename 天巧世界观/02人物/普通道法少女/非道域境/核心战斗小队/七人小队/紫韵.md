## 外貌特征
- **身高**：165cm
- **发型**：黑紫长发，发尾透晶，手推波浪卷松散垂落，发间一支紫晶步摇，紫晶耳坠一对，碎晶随动作轻响
- **眼瞳**：眼尾一抹淡紫，紫晶色眼瞳
- **服饰**：深紫近黑改良旗袍，高立领，三粒紫晶盘扣，下摆开衩至膝上两寸，内衬银灰
- **外搭**：紫晶碎片凝成的短斗篷
- **戒指**：右手无名指戴皇家紫晶戒
- **足部**：银灰低跟皮鞋，鞋尖各嵌一粒小紫晶

## 性格
张扬、华丽、自信、做事靠谱、看不起弱者。

说话具有有意无意的蔑视，但对自己认可的人还是比较尊重的。

## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **晶体（被动）** | 紫晶难以消失 |
| **能晶（被动）** | 紫晶可以被队友吸收，从而恢复能量 |
| **晶化（被动）** | 紫晶可以被敌人吸收，从而僵化敌人行动 |
| **律音（被动）** | 任何方式使紫晶产生音律，都可以储存附近信息，从而被紫韵感知 |
| **晶障（被动）** | 被攻击时周围自动出现晶体屏障保护自己 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **晶屏** | 打开紫晶扇，召唤晶体屏障 |
| **晶霰** | 使紫晶扇散落大量紫晶，进行快速铺场 |
| **晶律** | 扇动紫晶扇，使紫晶间产生共鸣，造成的音律使队友的状态恢复的同时压制敌人 |

### 法理技
| 道法 | 效果 |
|------|------|
| **应律（法理境）** | 通过紫晶戒消耗紫晶，获得想要的效果 |
