## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **燃烬（被动）** | 绯火灼烧的伤口不会出现持续伤害，但会以伤口的形式直接愈合 |
| **绯（被动）** | 不管远近攻击都具有‘燃烬’效果 |

### 太刀·绯烬
| 道法 | 效果 |
|------|------|
| **绯烬·十文字** | 交叉二连斩，中心区域具有破甲效果 |
| **绯烬·居合** | 拔刀瞬斩，火焰延迟显现 |
| **绯烬·燕返** | 一剑格挡后瞬间在敌人前后各一剑 |
| **绯烬·一闪** | 瞬移，对途径进行瞬身斩 |
| **绯烬·散华** | 绯烬刀身碎裂冲向四周，然后重新汇聚 |
| **绯烬·一线天** | 蓄力，斩出一道极细的绯色一线，进行大范围斩击 |

### 狐面
戴上狐面后，周身会燃烧火焰，并将‘燃烬’替换为‘妖火’。

| 道法 | 效果 |
|------|------|
| **妖火** | 火焰会造成禁疗、持续伤害以及致幻 |
| **环身火** | 隐藏动作，灼烧靠近的敌人 |
