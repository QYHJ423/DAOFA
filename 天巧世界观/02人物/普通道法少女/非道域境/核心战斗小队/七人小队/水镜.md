## 外貌特征

### 浅系（150cm）
- **发型**：墨蓝色长发，及腰，发尾微卷，用一根浅蓝色丝带松松绾着。碎发垂在耳侧，风吹过时会轻轻飘动
- **瞳色**：浅蓝色眼瞳，瞳孔深处有一圈极细的墨蓝色环纹
- **服饰**：浅蓝色交领襦裙，外罩一件半透明纱衣，纱衣上有水波纹暗纹
- **腰带**：墨蓝色丝绦
- **足部**：浅蓝色绣花鞋，鞋面绣水波

### 渊系
墨蓝与浅蓝正好反着。

## 性格

### 没分裂时
温柔、做事果断、杞人忧天、责任心强、害羞不敢轻易发言；会根据情况使用两套能力。

### 分裂后（两个人格）

#### 浅系人格
- 温柔、杞人忧天
- 总是怕队友状态不好，发现队友有伤或者污染就赶紧治疗净化
- 遇到敌人就赶紧收集情报，然后找队友
- **被队友一摸就不知所措**
- （法理境前只用浅道法，现在渊道法用得不太习惯）

#### 渊系人格
- 强势，经常对队友的失误指指点点，并强制要求其去治疗
- **被队友摸就摸回去**
- 遇到敌人发现可以打，就上去打
- 和另一位有交流后，就会在另一位收集完情报后叫她退下，然后自己上去试试
- （法理境前只用渊道法，现在浅道法用得不太习惯）

## 道法

### 浅渊镜（法理境）
不需要穿过就可以切换能力，同时两个人格可以交流了。

### 浅
水镜通过镜子，形象从墨蓝变成浅蓝，使镜子透明可以看到背面。

| 道法 | 效果 |
|------|------|
| **涟漪（被动）** | 感知，同时会加强对感知者周围的感知 |
| **映照** | 从镜子里出现地图；可以通过各种方法完善信息使地图更加完善，从而获得敌人的形象、动作、意图 |
| **倒影** | 制作镜像吸引敌人 |
| **洗涤** | 治疗伤痛、精神，清理污染 |
| **浮光** | 敌人看到的位置与实际不符 |
| **波涛汹涌** | 从镜子里召唤水流进行攻击 |

### 渊
水镜通过镜子，形象从浅蓝变成墨蓝，使镜子不透明，看不到背面。

| 道法 | 效果 |
|------|------|
| **深渊（被动）** | 攻击具有压力，具有极高的伤害且吸附敌人 |
| **深潜（被动）** | 隐藏自己存在 |
| **深渊凝视** | 看到敌人一段时间或自己被看到一段时间，就可以对敌人造成精神攻击 |
| **沉没** | 将敌人或者攻击吞掉 |
| **涤荡** | 更强的清理污染，但会造成伤害 |
| **暗流** | 看不见的攻击 |
