## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **熔金·百锻（法理境被动）** | 可以随意调整金属形态 |
| **熔金（被动）** | 每次变化形态都会提高匣的温度，直到熔化 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **千刃·洪流** | 瞬间从千刃匣里飞出金属洪流，化作千把刀刃为己所控 |
| **千刃·归匣** | 强制将散落在外无法操控的武器熔化召回 |
| **熔金·铸阵** | 气化金属，以自身为中心，对周围进行切割和灼烧 |

### 法理技
| 道法 | 效果 |
|------|------|
| **百冶·匣（法理境）** | 将整个气化千刃匣熔成一把剑（眼瞳变成月白色） |
| **匣·寒刃（被动）** | 匣刃奇寒无比，难以熔化；每次挥刃都能砍出一道冻结周围的剑气 |
| **匣·剑破万法（被动）** | 纯粹的锐利，甚至可以切开一些不应该被切开的东西 |
