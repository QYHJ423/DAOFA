# 道法少女·幻姬（星野鈴）

## 基础信息
- **道号**：幻梦星辉·终焉圣剑·永夜辉光姬
- **代道号**：幻姬
- **本名**：星野鈴（ほしの すず）
- **等级**：道仪境（B级）
- **成为道法少女时间**：2006年

---

## 外貌特征
- **身高**：156cm
- **发型**：黑色长发及腰，发尾渐变为银白色。额前碎发用一枚星形银扣固定，两侧各垂一缕细发
- **瞳色**：浅金色
- **上衣**：白色水手领短袖衬衣，银蓝色领结，领结中央嵌一枚星形水晶
- **下装**：深蓝色高腰短裙，裙摆渐变为银白
- **披肩**：半透明银灰色纱质披肩，点缀细碎水晶片
- **腰饰**：银蓝色缎带蝴蝶结，垂下两端缀星形银片
- **袜**：白色过膝长袜，袜口镶银线星纹
- **足部**：银白色低跟短靴，靴口各嵌一粒蓝宝石

幻光

## 法理
- **星辉幻光剑**（具有幻光：无法被看见）

---

## 道法

| 道法 | 效果 |
|------|------|
| **辉光** | 闪光 |
| **星辉闪耀** | 数个光弹 |
| **星辉沐光** | 挥剑洒下星辉般的光芒，光芒落在队友身上，恢复队友伤势 |
| **幻光隐匿** | 用幻光包裹身躯，隐藏自己或队友 |
| **星辉斩** | 挥剑斩出月牙形光刃，砍中具有眩晕效果 |
| **辉光幻影** | 出现四个幻姬，只有一个真的 |
| **终焉一闪** | 汇聚能量化作一缕流光，进行一次直线突刺攻击，敌人可以抵挡实体攻击，从而把幻姬挡住，但流光具有穿透效果 |
