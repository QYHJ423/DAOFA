## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **青龙偃月（法理境被动）** | 每次使用道法都会积累，使下一次道法效果更强 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **立春·东风破晓** | 解冻之风，破除敌方防御并驱散队友负面状态 |
| **雨水·獭祭** | 召唤细雨化作雨网，束缚敌人行动，同时缓慢恢复队友伤势与道法 |
| **惊蛰·春雷乍现** | 木生雷，极速突刺，附带高频雷电麻痹，造成短暂僵直 |
| **春分·日月平分** | 双剑一阴一阳，攻守兼备，弹反 |
| **清明·断魂** | 凄冷肃杀之剑，对残血或被标记的敌人造成无视防御的致命真实伤害 |
| **谷雨·万物丛生** | 插剑化林，大范围青藤狂暴生长。缠杀敌人并吸取生命力，同时为队友提供强力减伤与持续恢复 |
