# 道法少女·朱雀（孙瑾荷）

## 基础信息
- **道号**：朱雀
- **本名**：孙瑾荷
- **生卒**：1568—1600年（享年32岁）
- **觉醒成为道法少女时间**：1578年（10岁）
- **身份**：1600年[[四象小队]]成员之一；[[天姝]]弟子
- **性格**：重度社恐，外柔内刚，比较强硬；被盯太久会脸红；说话怯弱、温柔、轻言细语，激动时还会结巴或者语速变快；打灾兽时会快速地说“抱歉”一类的话，同时下手特别狠；想要发言权时会结结巴巴地说话并小小地直接动手争取发言权（如果自己的要求别人不听还会再烧一遍，如果还不听才会放弃）。

---

## 外貌与道仪
- **身高**：141cm
- **发型**：赤红长发用一根金簪高高挽成发髻
- **瞳色**：琥珀金瞳
- **服饰**：身着朱红与墨黑交织的襦裙，内有素白内搭
- **羽翼**：身后巨大羽翼。平时巨大羽翼把身体拢在里面，还把脸埋在宽大的朱雀羽扇后。

## 道法

| 道法           | 效果                                           |
| ------------ | -------------------------------------------- |
| **南阳明火（被动）** | 至刚至阳之火，具有真伤与净化效果                             |
| **立夏·红杏出墙**  | 对队友进行火焰附魔                                    |
| **小满·星火燎原**  | 挥洒无数火星，落到敌人身上或地上，就会迅速蔓延形成火海；落在队友身上会进行治疗与勇气增益 |
| **芒种·火树银花**  | 指定区域瞬间形成剧烈爆炸                                 |
| **小暑·火雨流星**  | 召唤火矢，进行大范围轰炸                                 |
| **大暑·赤地千里**  | 以自己为原点将大范围空间笼罩在极强的火焰当中，持续一段时间                |
| **南阳离火枪**    | 无法主动释放道法；通过注入的法力，获得数倍于注入法力的力量，注入法力越多倍数越多     |

## 生平结局
在1600年中，与[[四象小队]]一起越级对抗苍渊灾兽，后遭遇空间风暴，被卷入异界，最终阵亡。
