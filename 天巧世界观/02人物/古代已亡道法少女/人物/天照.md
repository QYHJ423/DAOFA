# 道法少女·天照（藤原京子）

## 基础信息
- **道号**：天照
- **本名**：藤原京子（ふじわら　みやこ）
- **生卒**：730—831年
- **成为道法少女时间**：742年（12岁）
- **突破道域境时间**：11年后（753年，23岁）
- **身份**：天何弟子；
- **派系**：天照系（自称：阴阳师少女）

---

## 性格与话语
骄傲，端方，对外说话像在念诏书；对日本的一切有一种**恨铁不成钢的温柔**。

---

## 外貌与道仪
- **身高**：143cm
- **发型**：墨黑长发在顶上绾成唐式高髻，横插一支金步摇，两缕鬓发垂至锁骨
- **面部**：眉心一点朱红，绘作日轮
- **服饰**：绯色高腰襦裙，外罩月白半臂，披帛如日晕绕于臂间；裙摆绣着海浪与三足乌
- **配饰**：腰间悬一面唐镜，镜面以绢覆之，从不示人
- **足部**：唐式云头履

## 道域：高天原·八咫照临
天穹裂开一线，光自缝中倾泻而下。地面化作白金二色，一座唐式宫殿与一座日本神社重叠在一起：朱柱、白壁、唐瓦、桧皮葺，分不清哪一半是哪一半。天上悬着一面巨大的镜子，镜中映出的不是天，是域中每一个人的背影。

| 效果 | 说明 |
|------|------|
| **①长明于世** | 自己不死，道域不破 |
| **②神罚之辉** | 灼烧邪祟，时间越长神罚越强 |
| **③常世** | 道域中所有队友免疫负面；但会被持续灼伤，自己没事 |
| **④万世一系** | 域中友军所受之伤由全体分担。一人未死，则无人先死 |
| **⑤神隐** | 每隔一段时间自身便会隐藏于“天之岩户”几秒钟，短时间无法被发现，复出后则光耀全域 |

## 道法

### 被动与强化
| 道法 | 效果 |
|------|------|
| **常世之辉（被动）** | 早期自身会控制不住地散发强光与高温，并会持续净化周围；后期会持续净化周围（早期天蓬一直用雨神剑帮忙压制，直到天照能自己控制强光与高温为止） |
| **八咫乌** | 召八咫乌，乌飞过之处，日光随之 |
| **神代之火（法理境）** | 短时间内燃烧自己，大幅度强化自身；但结束后会无法行动 |

### 八咫镜
| 道法 | 效果 |
|------|------|
| **镜反·八咫（被动）** | 反弹光线技能；被攻击时会反弹一部分物理或道法伤害 |
| **神威·八咫** | 悬于空中，照耀战场，使被照到的敌人被灼伤且无法隐身 |
| **天岩户之盾** | 八咫镜制造光之壁垒，对一定范围的队友进行防御 |
| **天照·万物** | 被攻击后，将镜子对着敌人之后会显现敌人能力 |
| **天照·高天** | 通过镜面折射进行瞬移 |
| **天照·神似** | 以镜照敌，学其术。只得其形，不得其神，且只能用一次 |

### 天丛云剑
| 道法 | 效果 |
|------|------|
| **草薙·斩空（法理境）** | 极其锋利的光之剑气，无视防御，破除防御 |
| **拨云见日** | 破除幻境 |
| **布都御魂斩** | 挥出附有绯红的太阳之火的一剑，对一切污秽和灾兽具有极强的杀伤力 |
| **天岩户·天照降临（道域内）** | 主动进入“神隐”状态，并减弱道域所有效果，积蓄力量；当复出时斩断高天原一切，范围广，无视防御，净化一切，并退出道域 |

## 生平经历（概要）
详见：[[天照生平|天照生平]]
- **753年**：因前辈们不要命地解决异界终焉灾兽而决裂，将雨神剑还归天蓬，回老家创立“[[天照系]]”。
- **831年**：三灾时期，带领徒子徒孙与所有道法少女一起对抗终焉灾兽，战死。
