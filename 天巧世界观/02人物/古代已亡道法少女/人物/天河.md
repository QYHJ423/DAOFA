# 道法少女·天河（李世凰）

## 基础信息
- **道号**：天河
- **本名**：李世凰（小名：凰奴）
- **生卒**：600年—831年
- **成为道法少女时间**：612年（12岁）
- **突破道域境时间**：6年后（618年，18岁）
- **身份**：[[天何]]弟子；二凤妹妹；公主；红娘
- **性格**：喜欢给人牵线

---

## 外貌特征
- **身高**：158cm
- **发型**：青墨色长发束成高马尾，发尾渐染金红
- **花钿**：一抹朱砂花钿
- **瞳色**：左眼青金色、右眼赤金色
- **外袍**：交领右衽长袍，青底朱纹，袖口宽大如流水翻卷
- **腰带**：腰束黄玉带
- **肩甲**：右肩覆一片金红凰羽肩甲，左肩素青
- **裙摆**：青黄红三色层叠渐变，绣暗纹——上游为山川、中游为城池、下游为星野
- **足部**：乌皮六合靴
- **配饰**：大腿系一根赤绳，坠一枚青玉珠

## 道域

### 银汉凰宫
**形象**：一个非常华丽的天上宫殿

### 道域效果
| 效果 | 说明 |
|------|------|
| **天河长流** | 自己不死，道域不破 |
| **天命凤凰** | 天命加持，化凶为吉 |
| **共赴银河** | 可以汇聚道域中所有道法少女的力量为己所用 |
| **紫微君临** | 汇聚的力量越多，质变的越强 |

## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **银汉沐浴** | 在银汉之下，法力不会彻底枯竭；状态会慢慢恢复 |
| **天河不息** | 击杀敌人恢复法力 |
| **凰羽垂天** | 攻击会附带‘天火’、‘天水’印记：‘天火’造成持续伤害、‘天水’延缓敌人行动 |
| **凤求凰** | 容易吸引别人 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **天河倒卷** | 召唤天河之水形成屏障将敌人的攻击挡下，并将敌人攻击卷入河流之中，然后经过洗礼后还回给敌人 |
| **鹊桥** | 瞬移，可带人 |
| **水火不容** | 引爆水火印记，对敌人造成极大的伤害 |
| **越银河** | 可通过银河路径进行快速移动 |

### 特殊技能
| 道法 | 效果 |
|------|------|
| **紫微星佑（特殊触发仅一次）** | 彻底死亡时，帝星入体重塑身躯 |

---

### 道域技（道域巅峰）
| 道法 | 效果 |
|------|------|
| **天策** | 道域中，任何情况下队友与自己都不会死不会败，根据逆转的程度付出代价 |
| **神威天策·盛世太平** | 极高的伤害。根据共鸣的多少再额外进行伤害的质变，与其他的共鸣可以叠加 |

---

### 法理技

#### 巨阙天弓
| 道法 | 效果 |
|------|------|
| **天河引** | 释放一道银河般的光矢，对敌人造成伤害，并留下银河路径 |
| **天河贯日** | 极具贯穿性的一箭，距离越远伤害越高（通过银河路径会增加银河长度） |
| **星落如雨** | 朝天射出一箭，在一段时间之后会出现大量箭矢跟踪敌人 |

#### 长河槊
| 道法 | 效果 |
|------|------|
| **长河奔流** | 突进式贯穿，并形成后浪再造成伤害，距离越远伤害越高、后浪越多（通过银河路径会增加银河长度） |
| **星火燎原** | 一记横扫散落‘天火’ |
| **百川归流** | 形成天河将敌人冲刷过来 |
