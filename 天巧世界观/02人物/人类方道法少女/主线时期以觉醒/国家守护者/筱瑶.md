# 道法少女·筱瑶（季淑贤）

## 基础信息
- **道号**：筱瑶
- **本名**：季淑贤
- **出生**：1992年
- **觉醒成为道法少女的时间**：2006年
- **等级**：法理境（A级）
- **身份**：
  - 我国早期五位国家守护者之一，负责不同片区。

---

## 经历与性格
- **性格**：外柔里刚，温和豁达；做事认真，不想留有遗憾；不喜欢读书，但喜欢学校。
- **求学经历**：一边上学一边战斗，并在2009年考上一所很好的大学。但由于永世之痛，几乎没有去上。余波五年结束后，边做守护者边重新上大学。

---

## 外貌与道仪
- **身高**：145cm
- **服饰**：青绿渐变道袍，广袖如竹叶层叠，腰束素白丝绦
- **发饰**：发间一支竹节玉簪
- **特殊**：九柄竹灵剑虚悬身后如扇形展开，足踏清风，行止间竹影婆娑
- **配饰**：苍竹剑随身侧，剑鞘如青竹一节

## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **势如破竹（被动）** | 攻击具有破甲效果 |
| **节节高（被动）** | 连续攻击同一目标，会使自身道法效果递增 |
| **贞根·灵剑（被动）** | 身旁会形成竹灵剑附体，最多九剑 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **虚心有节** | 形成一个竹空护盾，并获得持续一段时间的格挡 |
| **竹影婆娑** | 形成数个与自己相同的幻影 |
| **竹叶飞花** | 挥出大量竹叶利刃，大范围切割敌人 |
| **雨后春笋** | 恢复状态，并恢复竹灵剑数量 |
| **节外生枝** | 突进攻击，命中后在敌人额外形成副剑造成贯穿，并形成束缚 |
| **百草丛生** | 用苍竹剑以及九把竹灵剑作为阵法核心，制造一片竹海幻境迷惑并困住敌人 |

### 法理境技能
| 道法 | 效果 |
|------|------|
| **一竹百节（法理境）** | 一剑斩出，剑气如竹节一般，对命中的敌人造成百段伤害 |
| **万剑归宗（法理境）** | 经过引导，结束阵法，并使竹海形成数万竹剑持续攻击敌人，最后再出现一个超巨大的苍竹剑斩杀敌人 |
