# 道法少女·霜华

## 基础信息
- **本名**：白曦月
- **出生**：2000年
- **成为道法少女时间**：2008年
- **年龄**：18岁（[[主线时间|主线开始年龄]]）
- **境界**：爻衡
- **身份**：[[天巧]]妹妹，[[道法少女/天巧世界观/02人物/人类方道法少女/主线时期以觉醒/彼岸|彼岸]]弟子
- **道号**：道法少女·霜华

## 特殊说明
没有[道灵](天姝.md)的原因是：[[天巧]]正好回去，[[天姝]]就没有安排道灵，让天巧代替了道灵的作用，顺便增进兄妹感情。

## 道仪（158cm）
棕色单马尾，身高158cm，衣服是蓝为主金紫为辅形象是类似军人的服饰。军装上面扣子都是霜的形状，臂章是上面是雪花、闪电（根据这个的不同可以看出实力），下半身是百褶裙样式的。

## 权能
**寂灭**——（形象是冰雷）（效果类似量子潮汐原理）

## 法理
军刀和枪

## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **寂灭之息（被动）** | 行动无声无息 |
| **无声消逝（被动）** | 攻击具备极强的穿透，不会产生爆炸与巨响，直接使击中的目标区域无声地消失 |
| **抹除（法理境被动）** | 随着攻击的强度，慢慢剥夺敌人的部分存在 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **瞬雷** | 抹除沿途过程，直接到达目的地 |

### 枪（法理）
| 道法       | 效果                                            |
| -------- | --------------------------------------------- |
| **绝对零度** | 打出如黑色闪电般的一击，击中目标后停滞其能量运转，做到沉默与选择行动            |
| **雷霆万钧** | 寂灭沿途过程，直接打击敌人，将敌人命中部分寂灭掉，并从命中部分延伸出去，慢慢寂灭掉其他部位 |
| **死星**   | 极致的穿透力，可以轻易破除敌人防御，打出空洞                        |
| **凝滞之境** | 打出一个特殊立场，可以削减能量，并将范围内的事物固态化成‘冰块’              |

### 剑（法理）
| 道法       | 效果                                |
| -------- | --------------------------------- |
| **碎冰之音** | 将‘冰块’打碎，只听一声脆响，化作雪花消失             |
| **静默斩**  | 没有任何过程，直接斩出无视防御一击                 |
| **电光一闪** | 化作白光穿过敌人，寂灭如同闪电一般在敌人身体里流窜，使敌人身体消失 |
