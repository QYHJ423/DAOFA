# 道法少女·青蕊（叶心蕊）

## 基础信息
- **道号**：青蕊
- **本名**：叶心蕊
- **出生**：1989年
- **成为道法少女时间**：2005年（16岁）
- **等级**：法理境（A级）
- **身份**：早期人类方国家守护者之一，负责不同战区

---

## 经历

## 道法

### 被动技能
| 道法             | 效果                   |
| -------------- | -------------------- |
| **蔓延无方（被动）**   | 藤蔓生长迅速               |
| **附生·噬元藤（被动）** | 藤蔓触碰物体后可以迅速寄生，可以吸收能量 |
| **藤心净蕊（被动）**   | 自我净化、治疗              |
| **无根生（法理境被动）** | 不需要从具体的事物上面长出藤蔓      |

### 主动技能
| 道法 | 效果 |
|------|------|
| **荆心刺** | 具有破甲效果 |
| **幻藤弥香** | 迷惑敌人 |
| **万藤缠身** | 藤蔓缠绕敌人，限制敌人行动 |
| **青蔓障** | 藤蔓交织成盾，抵挡伤害 |

### 心脉同株
| 道法                   | 效果                           |
| -------------------- | ---------------------------- |
| **心脉同株·传音**          | 藤蔓缠绕队友，通过刺入从而进行通讯            |
| **心脉同株·涤秽**          | 藤蔓缠绕队友/自己，通过刺入从而将毒素/污染吸出     |
| **心脉同株·荣养**          | 藤蔓缠绕队友/自己，通过刺入从而提供增益         |
| **心脉同株·负荆请罪（法理境被动）** | 藤蔓缠绕队友/自己，刺入时会使目标难以成为别人攻击目标。 |
