## 道法

| 道法 | 效果 |
|------|------|
| **烬痕（被动）** | 被飞蛾点燃的目标受到伤害提高，同时更容易被她发现 |
| **烛火** | 点燃并持续灼烧小范围目标。如果目标被冷空气影响，会额外被战栗 |
| **起飞** | 创造一个小型风暴持续吸引目标并造成伤害。如果风暴中有被点燃的目标，火势会传遍整个风暴，同时扩大范围 |
| **气流** | 用冷气流减缓目标行动。如果目标被点燃，会将火熄灭，同时造成大量伤害 |
| **趋光** | 有被点燃的目标时可以使用。致盲目标，并快速移至目标身前 |
| **焚身** | 点燃鳞翅，自身速度大幅提升，且攻击自带火附魔 |
