# 道法少女·飞蛾

## 基础信息
- **本名**：於微芒
- **境界**：道仪境（故事中处于“回总部重新学习”阶段）
- **性格特点**：舍己为人，但有时会过于冲动。
- **身份**：天巧世界观下的道法少女，曾因长期战斗沾染灾厄而被判定为“堕落”，经净化后返回总部重新学习。

## 权能
**风、火**

## 道仪
- **身高**：136cm
- **发型**：褐色双马尾
- **眼睛**：深棕色瞳孔
- **服饰**：浅棕色大衣，内衬白色衬衣；下身浅棕色高腰直筒裤，黑色皮鞋。

## 法理
**鳞翅**

## 道法
### 被动·烬痕
被飞蛾点燃的目标受到伤害提高，同时更容易被她发现。

### 道法列表
| 名称 | 效果 |
|---|---|
| **烛火** | 点燃并持续灼烧小范围目标。如果目标被冷空气影响，会额外被战栗。 |
| **风起** | 创造一个小型风暴持续吸引目标并造成伤害。如果风暴中有被点燃的目标，火势会传遍整个风暴，同时扩大范围。 |
| **气流** | 用冷气流减缓目标行动。如果目标被点燃，会将火熄灭，同时造成大量伤害。 |
| **趋光** | 有被点燃的目标时可以使用。致盲目标，并快速移至目标身前。 |
