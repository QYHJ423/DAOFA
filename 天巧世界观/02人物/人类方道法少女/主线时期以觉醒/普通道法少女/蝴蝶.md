## 道法

### 被动技能
| 道法 | 效果 |
|------|------|
| **听风（被动）** | 极强的气流感知 |
| **乘风（被动）** | 风不会阻挡她，还会托举她，使她的速度很快 |

### 主动技能
| 道法 | 效果 |
|------|------|
| **风切刃** | 挥舞‘风切羽’，斩出交叉的极薄风刃，速度极快且破甲 |
| **引风** | 以双刃在周围划出气旋，能攻击或弹开部分攻击 |
| **顺风而行** | 利用气流吹拂的推力瞬间脱身，并留下风核微微牵引附近的敌人 |
| **顺风斩** | 蓄力后砍出一道风刃并跟随一刀真空刃 |
