# 道法少女·千叶（土御门樱）

## 基础信息
- **道号**：千叶（ちば）
- **本名**：土御门樱（つちみかど　さくら）
- **职业**：阴阳师。土御门家之女——土御门家承安倍家之统，她则是|晴明亲选的继任者。
- **觉醒成为道法少女时间**：安土桃山时代晚期（1582年）。
- **突破道域境**：200年后
- **所属派系**：天照系

---

## 性格与话语
年轻气盛，学得快，也敢用。

收扇的时候有个习惯，要先在掌心敲一下。

## 外貌与道仪
- **身高**：一米五左右
- **发型**：黑长直，发尾齐得像一刀裁过
- **上衣**：狩衣改制的短装，肩上留着狩衣的盘领与袖括
- **下装**：短款绯袴，只到膝上
- **足部**：白足袜与黑木屐
- **配饰**：腰间挂一轴小小的百鬼浮世绘，手里常持一把桧扇

## 道域：桔梗五芒·星曼荼罗
以桧扇在身前划出五芒星。地面浮起巨大的桔梗印，天空翻成一幅缓慢旋转的星图，星光冷而密，像一页摊开的旧历书。

| 效果 | 说明 |
|------|------|
| **①前知** | 域中所有人的行动轨迹都会先一步显出形来。预测得越久，误差越大 |
| **②吉凶位** | 依预测推算吉位与凶位，可指挥己方占住吉位，把敌人一步一步逼进凶位 |
| **③星曼荼罗** | 天上星图缓缓转动，转一圈，便是一日，可转吉凶 |
| **④五芒** | 桧扇所指，五芒所至。五芒星钉将钉住吉凶 |

## 道法

| 道法       | 效果                                  |
| -------- | ----------------------------------- |
| **禁咒**   | 在场地中施展规则性的咒语，违者立受负面之效               |
| **变咒**   | 可交换咒语的吉凶，也可交换敌我的增益                  |
| **噬灵**   | 吸收死魂灵，暂时提升战力                        |
| **替身**   | 与所役式神交换位置，在领域内尤见其效                  |
| **封咒**   | 可短暂沉默对方某一已知之术；若以符纸或符针控住经络，则能阻碍其魔力流转 |
| **返咒**   | 小范围反弹；若能反射光线，则可借光隐身                 |
| **音咒**   | 以铃铛发出固定频率之声，借此传播咒语，动摇敌方心神           |
| **千手百眼** | 一时幻出许多手与眼，协助战斗或劳作                   |
| **百鬼日伏** | 小规模召唤数只特定的鬼助战                       |
