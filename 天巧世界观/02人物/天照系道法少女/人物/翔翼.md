# 道法少女·翔翼（冬川云子）

## 基础信息
- **道号**：翔翼（しょうよく）
- **本名**：冬川云子（ふゆかわ　くもこ）
- **职业**：忍者。伊贺众出身，后为德川家的伊贺者。
- **出现时间**：安土桃山时代中期，天正九年（1581）伊贺之乱。
- **所属派系**：天照系

---

## 性格与话语
寡言，务实，从不多问一句。

打完仗会坐在地上数丝，断了三根要记账。

---

## 外貌与道仪
- **身高**：152cm
- **发型**：墨黑短发在脑后束成短马尾，额前挑出一缕银白，垂下来像一根没有落地的蛛丝
- **瞳色**：灰紫色眼瞳，光下泛着极细的银点，看久了会觉得那双眼睛里不止一双眼睛
- **服饰**：深蓝（蓝摺）的忍装束——短小袖、手甲、绑腿，腰间束一条灰白组纽，左挂钩绳，右插苦无
- **面部**：面上覆半张黑布，只露双眼
- **足部**：赤足蹬草鞋，足踝缠着几圈白丝
- **特殊**：背后八道丝线若隐若现，随呼吸轻轻颤动

---

## 权能
蜘蛛

---

## 法理（法理境）
- **蛛丝**
- **八苦无**

---

## 道法

| 道法 | 效果 |
|------|------|
| **蛛目（被动）** | 视野近乎无死角，可辨气流与魔力的细微扰动，暗中视物如昼 |
| **附足（被动）** | 行走无声，落地无痕 |
| **毒牙（被动）** | 丝线与苦无上淬有蛛毒。入血则四肢迟滞、五感渐钝；慢慢剥夺其行动能力 |
| **缀丝瞬影（被动）** | 带有丝线的苦无，只要丝线未断，自身便可以极快的速度到达苦无的位置 |
| **悬丝** | 召唤丝线；丝极细而韧，触碰者难以察觉，唯她能听见丝的颤动；常布于各处与苦无上 |
| **蜕壳** | 褪下一具蛛丝空壳代己受创，真身借丝遁出数丈 |
| **卵囊·散蛛** | 埋下卵囊，须臾孵出成群小蛛。可散于四野充作耳目，亦可扑上面目，乱人视线，亦可结丝束缚敌人 |
| **八足悬丝阵** | 以八苦无为锚，八道蛛丝自八方绷紧，如蛛足撑开天地。阵中之人一举一动皆被丝牵动——她要谁动，谁便动 |
| **切** | 当敌人被蛛丝束缚后，可使苦无远距离将敌人切割，并解除束缚 |
| **上臈之舞（法理境被动）** | 边跳舞边召唤丝线，舞蹈具有诱惑性，被其影响的则会被苦无咬进身体吸收能量，且身体上会不断被生成的蛛丝包裹；三步完成取敌首级 |
