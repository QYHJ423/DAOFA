## 基础信息
- **道号**：晴明（せいめい）
- **本名**：安倍明梨（あべの　あかり）
- **身份**：安倍晴明的后代；阴阳师；天照系门徒（自称：阴阳师少女）
- **出现时间**：平安时代晚期
- **觉醒契机**：在天照的道灵辅助下成为道法少女，被天照的道灵代为收作徒弟。

---

## 性格与话语
- **有点自私**：收的非自家的道法少女只是弟子，为天照系开枝散叶；她一直想找一个**自家出生**的道法少女作为继承者。
- 说话慢，笑得很浅；对活人不耐烦，对死人很有耐心。
- 撑伞的时候从不抬头。
- 经由阴阳师的知识开发自己的权能。

---

## 外貌与道仪
- **身高**：158cm
- **发型**：黄白色短发，一侧留一条细长的马尾辫，发梢掠过锁骨
- **服饰**：米白色的宽袖和风浴衣，白色的连裤袜，黑色的鞋子
- **携带物**：手里常年撑一把红黑色的日式和伞

## 道域：百鬼夜行·彼岸归途
现实被抽走了颜色，也被抽走了声音。人的气息被抹去，天空停在黄昏——也有人说，那是黎明。一轮红色的太阳挂在极低的地平线上，发出冰冷的光。远处有太鼓声，一下，一下，很近，又很远。

| 效果 | 说明 |
|------|------|
| **①逢魔** | 域中之人听不见自己的脚步，也闻不到自己的气味 |
| **②百鬼** | 她为百鬼之首，率队游行。妖物千奇百怪，有日常器具，也有传说里的名字 |
| **③一妖一咒** | 每一只妖都是一种诅咒，对域中之物持续侵蚀。鼓声越近，侵蚀越深 |
| **④彼岸** | 被侵蚀到极处的人，身上会一朵一朵开出彼岸花；花满之时，灵魂抽离，肉身腐坏，被送往三途川彼岸 |

## 道法

| 道法 | 效果 |
|------|------|
| **赋形** | 以魔力凝结的纸符折出式神，并短暂赋予其生命 |
| **操神** | 将式神附着于物体之上便可控物；附着于活物，则可与其通灵，或夺其心神 |
| **缚灵** | 将式神制成容器，吸纳活物的灵魂，困于其内 |
| **通灵** | 跨越生死结界与死魂灵对话，并能以式神将死魂灵拉回生界 |
| **死咒** | 瞬息之间在对方身上刻下数种诅咒，使其陷入负面之状，战力骤降 |
| **生咒** | 解咒 |
| **咒装** | 在器物上附着强化之咒而战；亦可附于衣料成甲，或将死咒藏于布中缠住对方，间接困敌 |
| **占星** | 占星是阴阳寮的看家本领，能提前预判对方的出招 |
| **浮世绘** | 在画卷上画出妖怪，召其助战；也能直接画出一方小世界，用以容纳 |
| **言灵** | 事先在口舌与喉间刻下极复杂的长咒，以大量灵力催动，可强令对方照她所说的去做 |
